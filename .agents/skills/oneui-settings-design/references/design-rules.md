# 外屏设置 UI/UX 设计规则

版本：1.0 · 2026-09-28。适用于本应用拥有的设置页面和配置弹窗。以下使用“必须”表示项目验收要求，“建议/初值”表示可在尺寸与可读性验证后调整的设计参数。它们不是三星官方公布的精确 token。

官方依据与九张参考图见 [参考分析](reference-analysis.md)；实际业务约束以项目根目录 `AGENTS.md` 和当前源码为准。

## 1. 页面骨架与信息层级

紧凑标题栏 → 可选功能总开关 → 可选预览或短说明 → 语义分组 → 可选相关设置。正文一个纵向滚动容器；标题栏保持可达，最后一项能完整滚动到不被系统栏、缺口或本工具悬浮入口遮挡的位置。

首页组织任务类别，二级页组织一项功能，三级页解决单个复杂配置。一般配置从首页两次点击内可达；应用选择、排序、校准等复杂流程允许额外一级。避免“其他/高级设置”成为无规则的收纳箱。

- 顶部：返回、短标题，必要时一个搜索/编辑动作；长标题自然增加高度，不用整体缩小字号解决。
- 分组：围绕同一对象或任务，不以“这里有三个开关”作为分组理由；每组建议 2–6 行，应用清单不受数量限制。
- 当前值：优先放在标题下，蓝色可扫读，如“4 列”“70%”“沿用当前方向”。首页类别说明使用灰色，不伪装为已选值。
- 说明：短句就近放置；较长限制放组外说明或帮助页。权限影响、作用范围、保存时机必须在决定前可见。
- 相关设置：页末 1–3 个上下文入口，深蓝底或普通链接组；不重复整套设置首页，不显示推荐营销内容。

首页总开关表达“用户是否启用外屏助手”；另行显示“未授权/未选择外屏/正在运行”等实际状态。不能因开关为开就宣称服务正在运行。

## 2. 视觉变量

### 色彩（深色首版）

颜色来自截图风格观察后的项目初值；应在真实渲染中复测，包括禁用、选中和按压状态。设置主题与运行时悬浮主题分开。

| 语义 | 建议值 | 用途 |
|---|---|---|
| page | `#000000` | 页面底色 |
| group | `#171719` | 普通圆角分组 |
| master | `#39393C` | 顶部主开关容器 |
| text-primary | `#F5F5F7` | 设置名称、正文 |
| text-secondary | `#B8B8C0` | 解释、组标签、未激活摘要 |
| accent-text | `#80AAFF` | 当前值、链接、选中说明，含 master 背景 |
| accent-control | `#3875F6` | 开关轨道、单选与滑条的激活标记；不承载小字号白字 |
| accent-control-on-master | `#4A88FF` | 主开关浅灰底上的激活轨道，避免深蓝轨道与背景对比不足 |
| switch-off | `#65656C` | 关闭轨道，白色滑块 |
| divider | `#38383D` | 低强调分隔线，不承担可点击边界的唯一提示 |
| related | `#0C192F` | 相关设置组 |
| danger | `#FF8A80` | 删除/覆盖的关键提示，配具体文字 |

选中状态必须有开关位置、勾选或单选圆点，不能只变蓝。控件必要的图形标记与相邻背景按至少 3:1 检查；装饰分隔线不承担此角色。禁用项保留名称、真实值与可读原因；不要把整个组降低透明度导致原因也读不清。若后续增加浅色模式，单独定义全部语义色并验收，不自动反转这组颜色。

### 尺寸与排版

全部为 dp/sp 初值，不从 748×720 等截图尺寸反推。文字使用系统 sans-serif；名称常规或中等字重，页标题较粗，不打包 SamsungOne 字体。

| 项目 | 可用宽度小于 360dp | 360dp 及以上 | 行为 |
|---|---|---|---|
| 页面左右留白 | 12dp | 16dp，宽窗口可 24dp | 在实际安全区域以内计算 |
| 分组圆角 | 20dp | 24dp | 同组共用外轮廓，内部行不重复圆角 |
| 组间距 | 16dp | 20dp | 组内靠内边距和细线组织 |
| 行左右内边距 | 14dp | 16dp | 图标、标题、分隔线起点对齐 |
| 单行最小高度 | 56dp | 56dp | 多行自动增高 |
| 标题＋当前值行 | 72dp 初值 | 72dp 初值 | 不作固定高度上限 |
| 顶栏最小高度 | 52dp | 56dp | 返回触摸范围至少 48×48dp |
| 顶栏标题 | 20sp | 22sp | 长名称换行或使用明确短名 |
| 设置名称/正文 | 16sp | 17sp | 不回退到现有 11–14sp 密集列表 |
| 当前值/解释 | 14sp | 14sp | 字体放大时保持完整可达 |
| 组标签 | 13sp | 13sp | 不承载唯一关键限制 |
| 行图标 | 24dp | 24dp | 应用图标可 32dp，装饰图标不单独获取焦点 |
| 设置触控目标 | ≥48×48dp | ≥48×48dp | 包括开关、返回、菜单、排序按钮和滑条命中区 |

常用间距按 4/8/12/16/20/24dp 阶梯安排。分隔线绘制为一物理像素，至少可见，不绕组外边；有图标时从文字起点开始。首尾行增加必要内边距，尾行不再画分隔线。

小字对比度至少 4.5:1；符合大字条件的文字至少 3:1。新设置页触控目标和对比度依据 [Android 无障碍指导](https://developer.android.com/guide/topics/ui/accessibility/apps)。这些要求不在本轮顺带修改运行时 Dock 已有的专项尺寸。

## 3. 配置类型到组件的决策表

| 配置类型 | 默认呈现 | 交互与提交 | 项目例子 |
|---|---|---|---|
| 功能总启停 | 独立主开关组＋实际状态说明 | 整行切换一次；写本地偏好；缺权限时给授权入口 | 外屏助手、常驻状态栏 |
| 简单布尔值 | 组内名称＋可选说明＋右开关 | 行和开关共用一次变更，成功后局部更新 | 震动、显示名称 |
| 枚举/策略 | 名称＋蓝色当前值行 | 进入带当前选中态的单选弹窗或专页；选中即保存并返回；取消不改 | 阻尼、图标风格、工具区位置 |
| 少量视觉枚举 | 配置专页中的示意选项 | 用勾选/单选语义；点击即更新本地示意并保存，留在专页查看结果；返回不撤销已保存值；窄屏竖排 | 左/右手、0°/90°/180°/270° |
| 连续或逐整数值 | 标题＋数值单位＋预览＋滑条 | 拖动只更新预览；松手写一次；取消回原值 | 大小、左右安全区、额外偏移 |
| 离散数值 | 当前值行或专门预览块的刻度选择器 | 明确允许值，不生成中间小数 | 控制中心 3/4/5 列、快捷栏 2–5 个 |
| 多个可同时开启的选项 | 独立开关或明确多选标记 | 不误用互斥 Radio；批量模式须有确定/取消 | 状态栏显示项目、参考图 1 的显示位置 |
| 按应用配置 | 搜索＋图标＋应用名＋当前策略/开关 | 开关是布尔；策略进入该应用专页；同名应用补包名 | 自动收起名单、应用方向 |
| 排序/增删 | 预览＋单列列表＋编辑入口 | 编辑页中拖动；提供上/下移无障碍替代；移除不靠滑动唯一入口 | 快捷栏按钮、控制按钮、侧栏常用项 |
| 系统权限 | 名称＋真实授权状态＋影响说明 | 打开系统页/授权流程；返回后回读，不用本地开关伪造权限 | 无障碍、通知、Shizuku |
| 当前目标选择 | 单选列表＋设备摘要 | 禁止选择主屏作为外屏；失联保留选择并提示 | 自动识别/已选择显示器 |
| 执行动作 | 动词明确的动作行或按钮 | 展示结果；耗时期间禁止重复提交；失败保留上下文 | 保存备份、导出、刷新、复制诊断 |
| 只读信息 | 普通信息行或可展开文本块 | 不添加无意义箭头/开关；诊断可复制 | 版本、兼容性、设备尺寸 |

普通设置清单中不堆横排单选按钮。列数、方向、外观这种需要看效果的配置可在独立编辑块里显示可视选项；“最多几个选项”不是决定控件的唯一依据，最终由标签宽度、预览需求和可达性决定。

## 4. 页面模式

**分组列表**：用于首页、权限、备份、常规功能页。正常浏览时行内最多一个主动作。列表滚动稳定，无变化不重设文本、不清空焦点。

**总开关＋依赖设置**：主功能关闭后，保留用户已配置的值。仅禁用确实依赖该功能的操作，并解释“开启后可调整”；能够离线配置的项目可继续编辑，说明“开启后生效”。状态栏左右留白和内容被控制中心共用时不能因常驻栏关闭而统统禁用。

**预览编辑器**：由预览、当前配置、控件组成一组。图 8 是主样式；图 9 的并排形式是宽空间变体。预览使用本应用的真实渲染规则或明确的本地示意，不截取其他应用画面。任何预览按钮均不能误执行实际系统动作；静态状态标“示意”，不伪造真实媒体或权限。

**应用列表**：搜索不跳转到另一套列表；搜索词、滚动和选中状态在返回后恢复。加载、空列表、搜索无结果、失败使用不同文案。安装/卸载后的失效规则可解释、可移除，不把包名当作可用应用。复用 `AppCatalogCache`，不另外建立持久化应用历史。

**介绍＋配置**：用于原生小组件、自动显隐等难理解功能。首段 1–3 个短句，完整帮助可进入专页；在窄屏将插画放在说明上方。示意图必须对应真实能力，不复制三星品牌插画。

**单选与弹窗**：短枚举就地选择，长列表/需要预览的选择进专页。自有小弹窗沿用 `DetailSheet` 的尺寸与动画责任，只有正文列表滚动，标题与操作可达。系统文件选择器、授权页与组件自带配置维持系统布局。

## 5. 状态、保存与返回

| 情况 | 用户可见行为 |
|---|---|
| 本地开关/普通单选 | 成功后立即显示最新值；一次操作一次写入；无须每次 Toast |
| 方向/左右手等视觉单选 | 选中即保存规则并保留当前预览页；未作选择直接返回零写入；选中后返回不撤销，不显示误导性的“取消更改”；保存方向不执行真实旋转 |
| 滑条触摸 | 拖动期间数值和示意跟随；`UP` 提交；`CANCEL`、离开编辑页取消未完成拖动 |
| 滑条 TalkBack/键盘 | 每次明确的调整动作可提交；不能依赖只有触摸才会发生的松手回调 |
| 带“完成”的排序/批量编辑 | 修改保存在编辑草稿；完成时完整校验后一次提交；取消不动原值 |
| 返回存在未提交草稿 | 返回时给“保留编辑/放弃更改”的明确选择；普通即时设置不反复确认 |
| 本地持久化失败 | 原值继续可见，说明未保存；不先关闭页面再报错 |
| 系统动作异步执行 | 显示正在处理；回调后读实际结果；目标显示器改变时停止提交并提示 |
| 权限未授予/被拒绝 | 保留偏好但注明当前无法运行；相关功能解释影响并提供用户授权入口 |
| 能力无法读取 | 显示“状态暂不可用”或“需真机确认”，不是显示“关闭” |
| 主功能关闭 | 已选值仍可查看；依赖关系决定禁用或允许离线配置 |
| 恢复/导入 | 先完整解析校验，展示覆盖范围，确认后原子提交；无效文件零修改；保留既有撤销能力 |

应用方向规则显示“下次从本工具打开时生效”；保存规则不立即强制旋转。媒体音量、整机流量等全系统范围写进说明。系统 UI 显示位置由系统决定的入口应原样告知，不以“外屏设置”名称暗示保证。

导航按真实来源返回：子页 → 来源功能页 → 首页；从搜索进入则返回原搜索结果；系统授权返回原页。路由记录参数、列表位置、搜索词、选中项及编辑草稿。旋转和可恢复重建不回首页，不自动重放外部动作；进程恢复只恢复 UI 状态，权限和显示器重新查询。

编辑手势与导航手势分工：滑条、输入、排序命中区域由控件拥有，父容器不能抢走。只在适用的弹层上沿用 `PanelSurface` 收起约定；普通 Activity 设置列表不新增全页下滑关闭。

## 6. 外屏与窗口适配

1. 使用当前窗口可用大小，扣除系统栏和真实缺口后计算；不依赖物理像素、不调整显示器 DPI、不根据横竖屏直接切换布局或控制列数。
2. `W < 360dp`：单列设置；图文上下排列；预览可收起但保留当前值；优先减少装饰和横向控件。
3. `360dp ≤ W < 600dp`：设置清单仍单列。局部“预览＋控制”只有两侧各至少 160dp、间隔 16dp且实际字体测量通过时才并排；否则上下。
4. `W ≥ 600dp`：可评估类别＋详情主从布局，不强制。每栏按自身实际宽度再检查；正文建议限制最大阅读宽度 640dp。单栏回退可用。
5. `H < 400dp`：默认紧凑顶栏，不保留展开大标题；预览初始建议不超过可用高度的约三分之一，支持展开。200% 字体允许更长页面，不压缩成不可读的小字。
6. 横向翻转/左右手仅改变控件顺序；不镜像真实缺口。四方向均以本次设备几何计算，不用硬编码“摄像头永远在右下”。
7. 处理本工具悬浮层遮挡时使用当前窗口与覆盖几何，并沿用现有约束；不为解决截图遮挡而隐藏全局系统导航、添加重复底部触摸页脚或伪造状态栏。

例如 720 物理像素在 440dpi 下约为 262dp，在 340dpi 下约为 339dp（扣除安全区域前）。二者都应先走窄屏单栏。参考图虽然方形且像素很多，并不等于平板布局。

## 7. 无障碍、动效和文案

- 字体以 sp 定义；检查系统 100%、130%、200% 字体。多行增长、完整滚动和切单栏优先，不截断关键值，不锁定系统字号。
- 设置行、开关、单选、滑条暴露准确名称、角色、范围/单位、已选/禁用状态。复合行避免 TalkBack 重复读三次同一个名称。图标不能成为无名称焦点。
- 排序提供拖动之外的可发现替代；所有关键动作无需长按才能发现。应用内文字、图标使用已有资源系统，新增文本集中管理。
- 页面转场建议 180–240ms，状态过渡 120–180ms；作为项目初值，服从系统动画倍率，关闭动画时立即完成。设置页面不引入弹跳；原有运行时 Dock 动画不因本规范而改变。
- 返回不插入额外成功页；保存的即时反馈以当前值变化为主。失败说明操作、原因及下一步，不吐出技术堆栈。
- 推荐文案：“控制中心列数 / 4 列”“应用方向 / 沿用当前方向”“通知使用权 / 未授权”。“系统控制（Shizuku）”保留专有名便于找到授权来源，接口类名留在诊断。

## 8. 验收矩阵

| 维度 | 最少检查 | 通过条件 |
|---|---|---|
| 本地构建 | README 的 assemble、单元测试、Lint | 构建成功；报告已有问题与新增问题 |
| 外屏尺寸 | 720×748 / 340dpi 和 440dpi；交换宽高；再检查真实窗口边界 | 不把 px 当 dp；标题/值可读；末项可点击 |
| 字体 | 100% / 130% / 200% | 无必要信息丢失，触摸目标不重叠 |
| 几何 | 0/90/180/270°，缺口有/无，左右手，系统导航显示/隐藏 | 内容位于真实安全区域；无主屏回退 |
| 交互 | 行/开关点击、单选取消、滑条取消、排序草稿取消、返回、搜索返回、键盘遮挡 | 一次动作一次结果；状态/滚动保持 |
| 外部状态 | 权限拒绝/撤销、Shizuku 断连、外屏失联、系统不支持、小组件取消 | 真实状态与可恢复路径；旧绑定保留 |
| 数据 | 旧配置导入、无效输入、备份/恢复/撤销、重复点击 | 偏好语义不变；无部分写入；保护字段保留 |
| 生命周期 | 打开/离开预览、旋转、息屏、重进设置 | 订阅按可见性释放；不后台抓屏或新增轮询 |
| 无障碍 | TalkBack 聚焦顺序、名称、状态、滑条调整、排序替代 | 与视觉动作等价；装饰项不抢焦点 |
| 原型/图片 | 普通浏览器本地打开，已有交互；最终图检查外框 | 相对资源完整；设备外框恰好一次、同步旋转 |

设计文档检查不能替代上述实施后的交互验收。模拟器不能证明三星原生卡片收录、系统授权路由、锁屏行为或真实外屏触感；这些单独标为物理真机待验证。
