# 与 mobile-android-design 配合使用

## 来源与定位

用户于 2026-09-28 提供 [wshobson/agents 的 mobile-android-design](https://github.com/wshobson/agents/tree/main/plugins/ui-design/skills/mobile-android-design)。本轮安装并阅读的版本为提交 `9b15b34b0bfc13a815cbfc2366e14ea549e09422`，可用 [固定版本入口](https://github.com/wshobson/agents/tree/9b15b34b0bfc13a815cbfc2366e14ea549e09422/plugins/ui-design/skills/mobile-android-design) 复核。

它是第三方 Material Design 3 / Jetpack Compose 实践 Skill，不是三星官方规范，也不是本项目架构约束。全局安装的原文保持原样；本文件记录本项目的采用方式，不在全局 Skill 内塞入 Flip5 规则。

设计时优先读取其 `SKILL.md` 和 `references/details.md`；再按需要读取 `references/material3-theming.md` 的颜色角色/窗口尺寸章节、`references/compose-components.md` 的列表/选择/加载章节、`references/android-navigation.md` 的状态/返回/深链章节。示例中的领域数据、依赖版本与自定义类型是示例，不能直接当作可编译项目代码。

## 两套 Skill 如何分工

| 决策 | mobile-android-design 的帮助 | 本项目具体采用 |
|---|---|---|
| 颜色和文字角色 | 使用语义主题，不到处写随意颜色 | 独立 `SettingsTheme` 角色；黑底、深灰组与蓝色当前值以本项目规则为准 |
| 页面适配 | 根据窗口尺寸采用合适布局 | 使用实际安全 dp 宽高和字体测量；窄外屏单栏；不因手机横屏或折叠就默认双栏 |
| 状态管理 | 状态上提、可保存页面状态 | `Prefs` 是偏好来源；页面状态保存搜索/滚动/草稿；Android Views 用等价机制，不要求 `rememberSaveable` |
| 列表性能 | 懒加载、稳定条目标识 | 长应用清单按需渲染/复用；稳定 ID 基于组件/包名或设置 ID；复用已有 `AppCatalogCache` |
| 选择控件 | 行级选择语义，子 Radio 不重复处理点击 | 一次触摸一次变更；布尔/互斥/多选区分；页面模式以 One UI 项目规则为准 |
| 异步状态 | 加载/成功/错误分别呈现 | 额外区分空列表、无搜索结果、未授权、目标失联和不支持，保留重试与原值 |
| 导航和深链 | 明确路由参数、恢复导航状态 | 来源栈、搜索返回、应用参数、组件结果回传，不把所有返回都送首页 |
| 无障碍 | 48dp 触摸范围、控件说明 | 名称/角色/状态/范围完整；装饰图标不单独读；可见文字与说明避免重复 |

上述是概念迁移，不是已完成的 Android 代码改动。实现时仍由当前技术栈承载，API 选择须对照官方资料和项目 SDK。

## 需要明确收敛的建议

- **动态配色**：外部 Skill 将 Material You 动态配色作为通用建议。本项目首版按用户截图固定深色与蓝色强调，不让壁纸改变参考风格；如用户另提主题需求，再单独设计。
- **Compose 技术栈**：其 `LazyColumn`、`MaterialTheme`、`NavHost` 等示例不能直接粘进 Java Views。参考职责与交互语义；不为外观重构强行迁移全项目或新增联网图片库。
- **卡片样式**：示例的 12/16dp 卡片和 Material 色面不是本项目的最终视觉 token；按任务分组，不套成每行一张 Card。
- **底部导航/FAB/抽屉**：这些是组件备选。当前设置是层级浏览，不自动加占用外屏高度的底部导航或浮动按钮；相关入口按本项目首页/返回体系安排。
- **返回确认**：示例 `BackHandler` 总是询问退出，不能照搬。普通返回直接回来源，仅存在未提交草稿时处理丢弃确认。
- **辅助说明**：不给所有可见文字再写同样的 `contentDescription`。复合控件由语义与焦点设计决定可访问性，避免重复读报。
- **颜色对比度**：使用色阶不是“对比度已通过”的证据。实际前景/背景组合仍按项目规则计算和实测。
- **性能与生命周期**：`remember` 或稳定 lambda 不是通用性能结论。先依据观察到的重建/加载问题解决；Views 中取消监听、后台回调与预览订阅也不能照搬 Compose 生命周期代码。
- **折叠形态**：折叠设备上的外屏、主屏铰链、多窗口是不同几何问题；不能通过一个折叠状态开关代替本项目指定显示器与缺口校验。

用户明确要求与项目 `AGENTS.md` 优先。两套 Skill 有差异时，Android 平台行为和无障碍由官方资料核实，视觉/信息架构以九图和本项目规则决策，业务权限与合法范围以当前源码为准。

## 联合使用的交付标准

一个设置页同时回答四件事：当前配置是什么、改变它会产生什么效果、如何返回或取消、不可用时下一步是什么。提交前核对：One UI 分组和状态层级、窄屏与大字适配、单一状态来源、点击和 TalkBack 语义、生命周期、配置兼容。

设计提案应说明采用了哪些通用原则以及哪些示例不适用；不为“用了两个 Skill”重复生成两套互不一致的 UI。外部 Skill 的后续升级只在相关任务中按需重新评估，不自动覆盖本项目设计。
