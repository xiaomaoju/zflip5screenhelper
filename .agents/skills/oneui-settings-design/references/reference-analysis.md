## 共同视觉语言

**观察**：页面底色接近纯黑，分组是低饱和深灰，没有夸张投影；圆角属于整组，内部细线从文字起点开始。白色主体文字、灰色解释、蓝色当前值与选中状态，承担不同语义。顶部标题粗于正文；列表行宽松，开关靠右。插画和预览占有独立空间，设置名称不会覆盖在复杂图像上。

**观察**：总开关所在浅灰条比普通设置组更突出；“开启”文字也采用蓝色。部分截图含淡化的禁用状态。图 4 的相关设置使用深蓝背景，与正常设置组有区分。图 3/9 的滑条呈灰轨道、圆形刻度与蓝色轮廓拇指，但图片不足以证明其拖动、保存或取消行为。

**推断及边界**：多数图底部固定的齿轮、九宫格与覆盖内容的渐暗区，形态和位置高度一致，看起来来自外部悬浮工具；顶部状态图标、底部系统导航线也不是设置内容。它们不纳入本项目设置组件。图 3/4 的悬浮返回背景可能是滚动或叠层状态，不能据此规定全页永久遮挡式导航。

这些图传达的是“按任务分组、当前值可扫读、效果靠近操作”的设置体系。只改圆角与颜色，仍用小按钮和长说明堆满页面，无法达到相同体验。

## 官方资料与取舍

以下为 2026-09-28 查阅的官方页面。摘取设计原则，不把网页示例当作特定 One UI 8.5 设置页的精确实现规格。所有颜色、间距、断点和动效时长的项目选择集中在 [设计规则](design-rules.md)。

| 来源 | 可支持的原则 | 本项目取舍 |
|---|---|---|
| [Samsung：Basic layout](https://developer.samsung.com/one-ui/layout/basic.html) | 区分观看与交互；把同类内容组织成聚焦块 | 使用预览/说明与设置分组；短外屏不固定保留大面积观看区 |
| [Samsung：Lists](https://developer.samsung.com/one-ui/comp/list.html) | 列表便于扫读；名称简洁；布尔开关在右；说明按层级放置 | 名称、当前值、解释分开；长中文名称允许换行，不能机械照搬英文字符限制 |
| [Samsung：App bar](https://developer.samsung.com/one-ui/comp/app-bar.html) | 提供紧凑和展开标题栏；展开可随滚动收起；返回时保持状态 | 外屏默认紧凑；大窗口才评估展开标题；维持来源页与滚动位置 |
| [Samsung：Buttons](https://developer.samsung.com/one-ui/comp/button.html) | 按钮强调立即动作；灰色/颜色区分强调程度；工具栏避免无意义层叠 | 导航使用列表行，执行使用动作控件；不把每个设置都做成大按钮 |
| [Samsung：Layout and typography](https://developer.samsung.com/one-ui/accessibility/layout-and-typo.html) | 支持文字放大与适当触控间隔，避免大字裁切 | 项目设置页面检查 100%/130%/200% 系统字体；放大后可重排和滚动 |
| [Samsung：Designing for large screens](https://developer.samsung.com/one-ui/largescreen-and-foldable/intro.html) | 多栏按 dp 宽度决定；大窗口减少无效拉伸 | 600dp 只是考虑主从双栏的起点，不能将截图的 720px 误当 720dp |
| [AOSP：Android settings design guidelines](https://source.android.com/docs/core/settings/settings-guidelines) | 标题具体、摘要展示状态；区分列表、实体、主设置和单选页面 | 采用其信息层级；视觉仍以用户 One UI 图为准，例如保留组内缩进细分隔线 |
| [Android：Settings / Views](https://developer.android.com/develop/ui/views/components/settings) | AndroidX Preference 提供设置层级与持久化；旧平台 Preference 已弃用 | 不引入旧 `android.preference`。当前项目是 Java 自绘 Views；采用等价组件语义，首轮不强制更换技术栈 |
| [Android：Make apps more accessible](https://developer.android.com/guide/topics/ui/accessibility/apps) | 建议 48×48dp 触摸目标；小字对比度至少 4.5:1、大字 3:1；提供控件语义 | 新设置组件执行此下限；外观像素尺寸和触摸范围分离，验证真实 TalkBack 焦点与状态 |

公开规范之间不完全一致。AOSP 倾向分隔组而非逐行画线，参考图则多处使用组内缩进细线；本项目采用参考图。AOSP 的“关闭主设置后禁用相关项”也不能机械套到“常驻状态栏”：若设置被控制中心共用，应保留并解释用途。以实际业务依赖决定可用状态。
