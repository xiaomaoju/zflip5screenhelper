# 应用桌面与九宫格文件夹方案

状态：文件夹及 P2/P3 整理入口已接入 Android 源码；0.15.8将Dock容量调整为4个常驻＋最多4个最近，见 [本轮验证记录](../dist/VALIDATION-0.15.8-dock-four.md)。同窗口菜单、Dock拖放及文件夹比例见 [0.15.7记录](../dist/VALIDATION-0.15.7-workspace.md)，初始整合验证见 `dist/VALIDATION-0.15.2-folders.md`。以下保留设计依据；当前实现规则优先见下一节。

## 当前实现与操作入口

- 排序菜单提供“手动布局”“新建文件夹 / 多选整理”“编辑布局”“撤销上次整理”“页面管理”“锁定布局”、名称显隐、密度和活动通知角标。空白长按进入整理状态并打开该菜单；“完成整理”退出辅助轮廓。
- 文件夹卡片在手动布局显示。名称排序、最近排序和搜索是全部应用的平铺视图；切回手动布局恢复文件夹，不会因此解散或丢失成员。
- 应用中心区域先识别目标中心，再处理普通让位。悬停1秒显示合并预览，松手保存；未满1秒在中心松手回原位，不执行未展示的插入。边缘/间隙仍用于排序，边缘翻页取消合并计时。
- 文件夹整张卡片可点击打开，预览小图标不独立启动。成员固定三列；常规字号尽量完整显示三行，大字号只滚动正文。长按成员排序，拖出卡片350ms后交给桌面，放下前仍归原文件夹。
- 打开后的文件夹居中显示，宽度上限240dp，常规宽度取宿主的76%，窄屏保留三列48dp以上触摸目标。标题11sp、数量为较小的次要文字，图标30dp、应用名称9sp；顶栏去掉额外上下留白，编辑/关闭采用16dp图形和48dp点击区。左右空白点击只关闭文件夹。
- 文件夹菜单支持重命名、添加、按名称排序、六种强调色、移到其他页、解散及撤销。成员菜单提供前后移动、移出桌面及移到其他文件夹。位置保护采用整个布局锁定，统一在排序菜单解除。
- 多选整理支持2–9项新建、加入已有文件夹和跨页移动；加入时显示来源，容量在选择及提交两次校验。批量操作与解散先显示数量/页数预览，点“完成整理”统一保存。
- 页面管理可查看、前后交换页面、删除空页；含内容的页明确拒绝删除。移动到页提供新页入口，末尾无内容的页自然消失。
- 拖到Dock的九宫格入口或固定区时，按指针位置插入、显示占位并让已有图标移开，松手保存；手动、名称排序及搜索结果均可固定。最多4个，满员提示先移出，不隐式替换已有常驻项。最近区最多4个，窄窗口按实际宽度减少，不影响完整任务页。应用中心展开时，可长按常驻图标重排，或拖回桌面区域取消固定，手动布局按落点恢复格位。最近任务及清理区不接受落点。
- 常驻应用从普通列表和文件夹成员中移走，桌面与Dock归属原子保存，不丢失应用。原文件夹剩1项时还原成单图标，取消固定后应用回到桌面；显式搜索仍可找到常驻应用，多选整理不重复添加。固定区与运行区同时有内容时显示0.5dp细线，两侧各1dp间距；只有一种分组时不占分隔空间。
- 长按应用、文件夹或成员的操作菜单复用当前安全宿主中的可滚动面板，避免拖动中图标卸载使原生弹出菜单锚点失效。系统返回先关闭当前菜单；菜单卸载时解除返回回调。
- 应用菜单支持别名（清空恢复原名）、系统详情及系统卸载确认。搜索包含名称、别名、全拼和首字母；找到文件夹成员后可长按“定位到”。多音字采用词库默认读音，可用别名补充目标读法。
- 活动通知角标默认关闭，复用已授权内存通知；排除持续通知、分组汇总及其他用户，文件夹按包去重聚合。断连清空。它不是其他启动器的私有未读数，不会自动授权。
- 单步撤销在当前应用中心会话有效，恢复完整组织与格位；目录或外部布局变更后作废。布局锁定也阻止撤销写入。
- 配置版本12 / 布局版本9。旧单格布局迁移保留位置；新格式校验文件夹2–9成员、全局唯一归属、2×2边界/重叠、名称、颜色及显示选项，失败整份拒绝。
- 保存的是一次已提交的逻辑布局及其行列规格。尺寸变化只做确定性投影，不写盘；未编辑时恢复原规格会恢复原格位。在新规格下完成整理，则以新规格作为下一份已提交布局。小于两行/两列时临时显示紧凑入口，保留成员，禁止此时新建/合并大文件夹。

## 已确认的交互

- 范围是应用中心中间的应用桌面区域，沿用现有搜索行、侧栏和底部 Dock。
- 大文件夹在桌面占 **2 列 × 2 行**，内部以 **3 列 × 3 行**显示实际成员的小图标，最多 9 个。
- **点击整张文件夹打开，再点击应用启动**；桌面预览小图标不独立响应启动，避免外屏误触。
- 拖动一个应用到另一个应用中心，稳定悬停 **1 秒**后进入新建文件夹预览；松手才提交。
- 文件夹支持打开、重命名、成员排序、移入、移出和解散。

参考图提供的是“大卡片中展示小图标”的组织方式。应用使用真实图标，不要求复制参考图的黑白图标主题。文件夹关闭状态占 2×2；打开后的浮层使用可读、可点的正常大小图标，不局限于原来的 2×2 物理区域。

## 一、桌面上的外观与操作

| 部分 | 规则 |
| --- | --- |
| 卡片范围 | 精确占据四个桌面格位，圆角及背景透明度与应用中心协调，不另加重边框 |
| 小图标 | 3×3 固定位置，最多九个；不足九个时从左到右、从上到下排，剩余位置留空 |
| 标题 | 文件夹名称放在卡片内部下沿的预留带中，不能挤出 2×2；单行省略，无障碍名称保留完整文本 |
| 图标比例 | 根据 2×2 实际宽高扣除内边距和标题带计算，保持原图比例；不拉伸图标 |
| 点击 | 卡片的图标区、标题及空白区均打开文件夹 |
| 长按移动 | 抬起整张卡片，保持 2×2 占位轮廓；跨页时仍按四格对象处理 |
| 长按原地松手 | 打开菜单：重命名、添加应用、整理成员、移动到、解散；整个布局的锁定在排序菜单 |
| 空白点击 | 普通状态不启动应用；文件夹打开时，浮层外空白先关闭文件夹 |

行列按桌面实际可用空间计算。五列页面可并排放两个 2×2 文件夹，余下一列可放普通应用。不能仅把一格图标视觉放大而让其他应用仍占用它遮住的格位。

若字体或窗口尺寸使桌面暂时少于两列或两行，使用带“9”等成员数量的紧凑文件夹入口作为临时显示；成员和大文件夹布局保持保存，空间恢复后还原。此时不允许新建一个无法预览落位的大文件夹。

## 二、创建文件夹

### 拖拽合并

1. 长按应用 A 抬起。
2. 移入应用 B 图标中央的合并区域，B 高亮并出现环形进度。
3. 在同一目标上稳定停留 1000ms 后，显示包含 B、A 的文件夹预览，轻震一次。
4. 预览同时显示 2×2 范围及周围图标将要移动的位置。
5. 松手后一次性保存新文件夹、两名成员和所有被调整的位置。
6. 拖开、返回、增加第二根手指、息屏或窗口移除，取消预览，不写半成品。

新文件夹默认命名“文件夹”，并提供“重命名”和“一次撤销”入口，不在拖拽松手后强制弹键盘。系统目录中 A、B 的身份不变；桌面不再同时保留这两个独立项。

### 合并与普通排序如何区分

- 拖到图标的**中央区域**进入 1 秒合并计时；此时固定目标，不能先把 B 挤走再追着移动后的 B 计时。
- 拖到格子的**边缘或间隙**执行普通插入、让位。
- 指针仍在允许抖动范围内时继续计时；离开目标区域或更换目标，计时归零。
- 位于翻页边缘带时，优先跨页，取消当前合并计时；页面停止运动后再识别新目标。
- 未满 1 秒就在目标中心松手回原位；边缘或间隙执行普通排序预览。不能发生没有预览的合并。

### 2×2 空间不足

以 B 所在位置附近为锚点，优先向右、向下展开；临近页面边缘时向内调整。先从试算布局移除 A、B，再寻找 2×2 放置区。

若范围内还有其他应用，优先移到本页最近空位，剩余项按原顺序放到下一页；需要新页时先展示预览。所有位置变化随一个事务提交，撤销时整组恢复。文件夹不跨页、不跨行边界、不与侧栏或 Dock 重叠。

### 其他创建入口

编辑模式提供“新建文件夹”，从应用选择器选择 **2–9 个**当前位于桌面的应用，指定名称并展示落位预览。取消选择不创建空文件夹。该入口也作为不便执行拖拽用户的替代路径。

## 三、向现有文件夹添加应用

| 情况 | 行为 |
| --- | --- |
| 拖到未满文件夹 | 高亮卡片，显示“加入 · 7/9”等真实数量；悬停 1 秒出现成员预览，松手加入 |
| 已有同一个应用 | 不重复添加；提示“已在此文件夹中” |
| 已有 9 个成员 | 显示“已满 9/9”，松手回到来源，不自动替换成员、不自动创建第二页 |
| 多选添加超过剩余容量 | 选择器显示剩余名额并限制新增选择，已有选择保持可取消 |
| 从另一个文件夹拖入 | 一次性完成来源移出和目标加入；失败时来源成员不丢失 |
| 将文件夹拖到文件夹 | 首版作为普通桌面移动，不嵌套，也不隐式合并 |

“添加应用”选择器应区分桌面独立应用、已在其他文件夹的应用和当前成员。跨文件夹操作明确显示来源，避免用户误以为是复制。

## 四、打开后的 3×3 面板

- 使用现有二级浮层的尺寸测量、动画与外屏安全边界，顶部显示名称、成员数及更多操作。
- 内容始终三列，最多三行；图标恢复正常可点大小并显示应用名称。高度紧张或大字号时只让内容区域滚动。
- 点击应用沿用现有启动路径；系统接受启动请求后，文件夹和应用中心一起关闭；失败则保留当前文件夹并显示原因。
- 返回键先关闭文件夹，再处理应用中心的收起与关闭。
- 长按成员可拖动排序；位置预览清楚显示插入位置，松手才保存。
- 拖出面板边界并停留约 350ms，收起文件夹面板并把同一个拖动交给桌面；未成功落下前，原文件夹仍保留该成员。
- 提供“移出到桌面”和“移动到其他文件夹”菜单，作为拖拽替代操作。
- 搜索结果可以找到文件夹中的应用，显示“位于：文件夹名”；点击直接启动，另提供“定位”以打开来源文件夹。

## 五、移出与解散

| 操作/结果 | 数据与界面行为 |
| --- | --- |
| 移出后剩余 2–8 个 | 保留文件夹，内部按剩余顺序补位 |
| 移出后只剩 1 个 | 默认自动还原为独立应用，优先占文件夹原左上格；其余三格释放 |
| 卸载后没有成员 | 删除空文件夹容器，不删除其他桌面项 |
| 主动解散 | 将全部成员恢复到桌面，按文件夹内顺序放置；先使用释放的四格，再使用附近空位，最后顺延到下一页 |
| 当前页没有足够空位 | 预览明确显示需要下一页，不丢弃成员、不覆盖其他应用 |
| 取消解散预览 | 保持原文件夹和全部成员原样 |
| 撤销 | 恢复文件夹名称、顺序、位置以及本次操作影响的桌面位置 |

解散只改变快捷入口组织，不是卸载。它使用可撤销操作，不需要反复确认；系统卸载是另一个明确命名的动作，并沿用系统确认流程。

应用暂时不可用或目录正在刷新不能当成卸载。只有可靠卸载事件或完整的新目录确认身份消失后，才整理文件夹成员；更新包期间保留位置。

## 六、统一的撤销与编辑规则

- 首版保留最近一次已提交的布局操作，覆盖创建、移动、加入、移出、解散及排序；在应用中心当前会话内有效。
- 撤销基于完整的变更前布局快照，不按当前图标位置倒推。
- 应用安装、卸载等外部变更发生后，先重新核对身份；不能通过撤销复活一个已卸载的应用，也不能覆盖更新后的目录。
- 空白处长按进入编辑模式，显示布局范围、文件夹轮廓、完成和撤销入口；普通浏览时隐藏这些辅助标记。
- “锁定布局”只保护位置及文件夹组织，不影响启动应用、搜索或阅读；用户可以从排序菜单解除锁定。
- 文件夹名称按可见字符长度设上限，支持中文、空格和常用符号；允许重名，内部身份使用稳定 ID。

| P1 | 编辑模式与锁定布局 | 日常点击启动，整理时才暴露辅助操作，减少误触 |

| P1 | 布局备份和恢复 | 包含文件夹、成员顺序及桌面位置；导入前全量校验，原子提交 |
| P2 | 多选整理 | 一次选择多项移到另一页或加入文件夹；9个容量限制在选择时可见 |

| P2 | 应用详情与卸载入口 | 使用系统支持的入口，显示位置仍受三星系统路由限制，禁止把移除快捷入口标成卸载 |
| P2 | 名称显示和密度 | 保留当前紧凑默认值，提供普通/易点模式，尊重系统字号 |
| P3 | 自定义显示名称 | 只改本工具中的标签，可随时恢复系统名称；不改安装包 |
| P3 | 搜索别名/拼音 | 本地索引，先核实中文应用的匹配需求，再选择有界实现 |
| P3 | 文件夹强调色 | 少量预设颜色用于辨认，确保深浅背景都可读，实际图标保持不变 |

不建议首版加入嵌套文件夹、超过9个后自动分页、自动联网分类、自动移动常用应用或仿系统完整桌面替换。这些会增加规则和误操作成本。用户手动分组不应被后台使用频率或最近任务刷新改变。

## 八、实现结构

基础版本的一维逻辑格位适合单格应用；文件夹阶段必须升级为真正的多格占用模型。

- `AppWorkspaceLayout`：升级为带节点类型的布局，普通应用占1×1，文件夹占2×2；统一碰撞检查、重排试算和事务提交。
- `AppWorkspaceView`：渲染应用与文件夹卡片、四格落点轮廓、分页及边界；只挂载当前页和相邻页。
- `AppDragController`：增加“普通拖动 → 合并计时 → 文件夹预览 → 松手提交/取消”状态；合并计时与翻页计时互斥。
- `AppFolderView`：负责3×3预览和可释放的图标绑定，不独立扫描应用目录。
- 文件夹面板：复用 `DetailSheet` 的尺寸与动画能力，负责成员点击、重命名和内部拖动；关闭时释放监听和计时器。
- `Prefs`：保存带版本的应用/文件夹节点、成员顺序和位置；纳入布局备份及配置导出。导入校验成员上限、重复身份、非法引用、循环/嵌套以及越界、重叠。

同一应用在桌面组织树或Dock常驻区中只归属一处；侧栏常用继续作为独立引用。目录缓存继续以当前用户的启动组件身份为准。0.15.7按补充需求以这一规则替代早期“Dock仅为重复引用”的方案。

跨尺寸策略建议：不同可用行列规格保存各自的位置投影，文件夹身份、名称及成员共享。首次遇到新规格时按稳定顺序重新安放，保证2×2不跨行；空间恢复后恢复该规格的位置。安装、卸载或分组改变后，其他规格下的旧投影在下次使用时按同一节点集合核对。不能靠屏幕像素坐标持久化，也不能为了放下文件夹修改显示器DPI。

## 九、实施与验收

1. 先完成并验收单格分页、拖拽、位置保存、取消路径。
2. 实现多格占用和2×2文件夹卡片；验证边缘、满页、旋转及字号变化。
3. 接入1秒合并、添加、移出、解散和单步撤销，再实现3×3打开面板。
4. 接入搜索定位、无障碍替代操作、备份迁移和锁定布局。
5. 根据实际使用再选择P2/P3，不在同一版堆入所有扩展。

必须覆盖：8→9加入成功、9→10拒绝；悬停999ms不合并、满1秒有预览；抖动不反复重启、换目标重新计时；2×2在右边/下边可放置；满页需要重排或新页；移出失败保留来源；2→1自动还原；解散9项不丢失；取消与撤销恢复整个受影响布局；搜索找到成员；包更新不丢位置；坏配置不部分生效。

本地构建、算法检查和模拟器交互检查与 Flip5 真机验收分别记录。真机重点确认：小屏触点、1秒悬停容错、文件夹打开尺寸、跨页拖拽连续性、三星系统边缘手势和目标外屏启动路由。
