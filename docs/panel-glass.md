# 通知与控制中心玻璃材质

正式悬浮窗采用一次性背景会话，保留通知和控制中心的功能与网格格位，小屏工具采用统一紧凑规格。试验页的自由位移、示例背景菜单不进入正式版。

## 所有权与边界

- `CoverService` 只在通知／控制面板显式开启时建立 `PanelGlassSession`。内容先构建，宿主在背景准备期间不可见；异步预算为150ms，到期显示轻量材质。关闭、息屏、断连、显示器坐标失效及低内存释放。配置关闭或省电模式不创建玻璃会话。
- Android 14及以上优先取所选显示器上最顶层、覆盖完整显示范围的应用窗口，以避免把自己的悬浮状态栏采进背景。顶层应用是浮窗或分屏时使用该显示器一次取样；此回退可能包含现有悬浮工具。Android 13使用显示器取样；更早版本沿用基础材质。拒绝、受保护内容、超时与几何不一致不再重试，不回退到显示器0。
- `PanelGlassSession` 持有背景纹理、统一显示坐标、AGSL程序、显式接入的视图与至多一层弹窗父层纹理。同一次打开的页内切换、编辑、详情复用背景；旧媒体控制与旋转方向入口也显式接入。正在准备或已降级的会话同样保留，页切换不触发重试；截图不保存、不轮询、不使用“保存外屏截图”的拆窗流程。
- `GlassBackdrop` 在串行工作线程预生成GPU模糊。原图最长边1024px，两份模糊最长边384px，半径分别按18dp、28dp及缩放换算。HardwareRenderer、Image、ImageReader和回调HardwareBuffer按所有权释放；迟到结果不得替换新会话。
- 窗口取样区分截图像素尺寸与屏幕显示尺寸：三星兼容缩放的普通 App 可返回等比例放大的 Surface，先映射到窗口实际显示范围，再生成纹理与模糊；不将原始像素尺寸当作屏幕坐标。不等比例裁剪、旋转尺寸错配及显示器取样尺寸不一致仍降级，受保护内容不重试。诊断同时列出取样尺寸和映射区域。
- `GlassSurface` 只对已绑定的面板树接入。布局变化时发现新增行、候选项和弹窗；绘制前仅检查已注册表面的可见坐标。没有玻璃自己的逐帧定时器。滚动、展开与拖拽采样位置随全局变换更新。
- 设置、应用中心应用列表、Dock、启动器和系统选择器不建立该会话；共享`Ui`不改。嵌在应用中心内的多任务页单独接入，见下文。`LevelSlider`、编辑网格和详情背景只在有会话时使用可选材质。

## 视觉约定

通知页中央只显示原背景的76%亮度，不增加模糊，标题无玻璃底；页边有圆角与连续向外折射。通知卡片使用28dp模糊，正文采用更亮的次级文字和局部暗衬底。设置、关闭按钮为圆形，删除与数量同属胶囊。

控制页中央使用18dp模糊并压暗，按钮、滑条和媒体卡各自成形，保留当前开启／未知／执行中／禁用语义。编辑候选项与详情白图标使用深色选中底；详情文字按钮沿用浅色选中底与深色文字。

0.17.1 以主顶栏为基准，`PanelUi` 统一运行时标题17sp、正文12sp、辅助10sp、动作槽36dp、间距4dp、内容边距8dp；候选 Tab 和搜索占位约40dp。编辑网格标签沿用控制页的字号偏好。`PanelActionSlot` 将36dp圆按钮绘为28.8dp，保留整槽触摸；编辑和详情直接使用紧凑测量尺寸，不再继承设置页48dp的大留白。文本动作保持相同高度，宽度随文字；动态隐藏的播放器按钮连同槽位隐藏，恢复后重新参加布局。通知侧滑保留44dp触摸区和文字标签，圆形图标表面同为28.8dp。不改主网格圆形磁贴、列数或系统操作。

`ControlSourceTabs` 现在仅是原生 View 宿主和无背景时的普通按钮降级。`OriginalLiquidTabs` 通过 ComposeView 直接调用作者原版 `LiquidBottomTabs.kt`、`LiquidBottomTab.kt` 及动画辅助文件，Backdrop 2.0.1 提供折射、色散、阴影与图文叠层。原文件按固定 commit 原样参与编译，原生宿主只对接来源回调、取消和多指防护、窗口生命周期，以及现有玻璃会话背景。组件以整体密度适配现有40dp槽，保留作者内部64dp轨道、56dp镜片及按压比例；设置与共享Ui不变。来源与校验值见 `docs/liquid-tabs-upstream.md`。`GlassToggle` 仍为原生View适配，使用已确认系统状态，未知态进入原选择流程。

NFC 主行及开关在回读时原位更新；状态和付款文字预留两行，执行反馈复用状态区，避免提示插入与整页重建造成两次尺寸跳动。写入确认到状态回读间保持禁用；未知结果和重试耗尽结束等待，不将旧状态作为新结果。关闭与断连释放现有订阅，不增加轮询。

Wi-Fi、蓝牙、移动数据、勿扰、飞行模式、手电筒、系统控制中心及自动旋转详情共用开关交互。点击后保留详情，复用原操作回调、状态回读或 Camera 回调结束过渡；一次性截止处理未确认结果。断连与状态失效同步打开的详情，迟到回调检查本次请求身份；手电筒只由匹配目标的回调结束等待。未知态先展开明确的开启／关闭文本操作。主网格仍保留圆形磁贴；通知设置和媒体系统选择器仍由系统呈现。

满屏页壳读取 WindowInsets 的物理圆角，半径减一像素覆盖抗锯齿接缝，展开过程中连续过渡至浮起圆角；子内容采用相同轮廓裁剪。候选 GridView 在绑定、重新挂载和临时回收结束时重新接入材质。滑条保留执行状态，但不因一次写入完成而切换整条边框颜色。

折射位移使用有界、单调的外向平滑曲线。通知、控制及多任务大背景板的折射带宽不超过12dp及局部几何上限，最大外向位移为带宽的80%（至多9.6dp），在窄边缘内增强扭曲感，同时减轻拖动越过背景文字后仍将其拉回板内的重影。其他控件保留22dp带宽上限及85%位移比例。通知页采样超出截图边界时只柔化边界的延伸颜色，避免把单个亮像素拉成白边，不镜像纹理、不折叠采样。文字与图标自身不参加背景模糊。来源 Tab 使用原版的隐藏图文叠层和组合 Backdrop：切换时镜片同时采样背景及覆盖到的多项Tab图文，原版自行处理局部放大、边缘弯曲及色散。此前自写的Tab缩放和AGSL折射已移除。新增的背景LayerBackdrop仅借用当前会话的sharp纹理，不新建截图；坐标由宿主与Canvas偏移对齐。无背景、低内存或卸载时销毁Composition并释放其图层，回到普通按钮。会话bytes仅统计其持有的背景位图，Compose活动图层不计入该数字。

详情打开前只记录一次当前本地父层，GPU合成仍在工作线程；最多保留一层。关闭或退出编辑确认窗会使旧结果失效。低内存降级在本次打开期间保持轻量材质，不能立即重新启用旧全窗／详情模糊。

## 验证入口

### 多任务页

`AppHubView` 通过 `taskPageChanged` 通知进入和退出，`CoverService` 持有独立的任务页 `PanelGlassSession`。进入时先隐藏宿主、关闭该窗口原有模糊和压暗，再走同一150ms取样预算；退出恢复应用中心原有背景。拒绝、超时、省电、关闭效果、断连和低内存均回到基础材质，本次任务页不重试；息屏、显示器变化和窗口移除释放会话。背景仅取所选外屏的一帧，不替代或新增任务快照来源。

多任务底板与通知页共用 `NOTIFICATION_PAGE`：中央保留背景原始细节并压到76%亮度，不增加模糊；宿主覆盖整块外屏并读取相同的物理圆角，内容单独避让缺口、状态栏及导航区域。任务页没有顶栏文字或按钮。三张任务预览在清理按钮上方的内容区居中；清理位于下方中央，复用控制中心 `PanelActionSlot` 的36dp槽位和28.8dp圆面。返回全部应用、刷新和重开失败任务放在长按菜单及无障碍动作中。

轻点空白处触发现有向下收起动画；识别只观察原触摸序列，不拦截或重写空白滑动。卡片及完整清理触摸槽不算空白；超过触摸阈值的位移、多指、取消、尺寸变化及长按不会触发轻点收起，空白滑动仍交由 `PanelSurface` 和既有轮播处理。

`TaskPreviewView` 本身是每个任务唯一的玻璃卡片，不再嵌套外框。它借用任务页持有的快照，等比居中裁切，圆角直接采用页面背景所用的系统物理圆角半径（同样减去1px防接缝），不按卡片尺寸等比缩小；没有圆角报告时采用24dp视觉回退，仅在卡片过小时限制为短边的一半。专用凸透镜将中心正立放大约1.15倍，连续过渡至边缘，配合弧面高光、内侧暗边与底部反光；不复用来源Tab的凹透镜参数。应用名、状态和锁定标记在透镜外。关闭效果或背景取样不可用时保留同轮廓的圆角裁切；缺少快照时在同一轮廓内显示居中图标，图标不放大或裁切；快照到达后仅进行120ms图像淡入，不改变几何。

玻璃取样期间宿主可能暂时不可见，显示回调必须立即调用任务页的 `previewsVisible()`，不能等待应用中心约3秒的任务刷新周期。已经发出的快照在这段短暂隐藏期间到达时，只要页面代次、挂载和任务身份仍有效，就接纳结果并清除请求中标记；退出后的迟到结果仍释放。该修复移除人为等待，不承诺系统快照接口本身的返回耗时。

已加载的256px预览按任务身份在当前任务页内缓存，滑出视口仍保留，左右返回直接复用，不重复向系统读取。缓存至多32项，与系统任务列表上限一致；关闭任务页、断连或低内存清空全部，任务消失或身份变化只清理对应项。先移除绘制引用再回收位图，同一页内迟到的有效快照也可入缓存，旧页面回调必须丢弃。除交互动画及有界淡入外没有渲染定时器。`recent-tasks-glass` 模拟器场景检查硬件渲染、中心裁切与凸透镜像素、全屏底板与单层卡片、居中小按钮、锁定与连续滚动、会话缓存复用、背景释放、低内存、返回应用中心及显示后立即请求／隐藏期间回调；原 `recent-tasks` 场景覆盖任务手势和失败回调。

`UiSmokeInstrumentation` 的 `panel-glass` 场景仅接受可丢弃模拟器。它使用正式渲染层，覆盖五种背景、通知像素压暗、平移坐标、控制高频纹理模糊、3/4/5列、30项容量、编辑拖拽与取消、模态纹理释放、通知突发更新和原始Buffer迟到释放。使用`-e rotation 0/1/2/3`检查方向。

真实外屏必须另行验证一次性取样、窗口合成、双白条和息屏重建。应用服务的`dumpsys`输出背景状态、准备时间、取样／预处理次数及当前已接纳纹理字节数；关闭后明确报告0B。该数字不包含系统合成器与驱动缓存，不能替代PSS／Graphics测量。

具体构建、性能口径、真机证据与未测项目见`dist/VALIDATION-0.17.0-panel-glass.md`。

### 单项上滑关闭与清理按钮

单张卡片上滑走 `AppRecentTasks.dismiss`，可关闭固定到 Dock 的后台任务，并保留应用的固定入口。批量×和 Dock 清理继续跳过固定应用；两种操作均保护任务锁、正在使用的窗口，并由系统接口在移除前再次校验任务身份、用户及显示器。

上拉采用渐进阻尼，预览最多横向收窄6%、纵向拉长8%，镜面高光和凸透镜随拉伸轻微增强；文字保持原比例。松手后从当前拖动位置连续向上滑出360ms，镜片短暂增加到约8%收窄、11%拉伸后恢复，不设置等待平台或第二段退出；后台关闭同时执行，动画期间暂存返回，成功后更新列表，失败则将原卡片弹回。未达阈值、取消或失败时300ms轻微超调回弹；多指、尺寸变化和卸载释放形变与动画，系统关闭动画时直接落到终态。静止无持续帧循环。

底部×继续使用控制中心36dp触摸槽、28.8dp可见圆面和同一图标规格。任务页独立 `TASK_ACTION` 材质加强深色底与明暗对比；没有可批量清理任务时只降低图标亮度，不把整个玻璃按钮淡至30%，也不改变其他控制中心按钮。

任务页从应用中心切入和独立打开均从整个页面位于屏幕下方开始，使用500ms平滑上移入场；背景准备结束后重新开始可见入场，缩略图请求与入场并行，不等待动画结束，也不增加人为延迟。应用中心普通入场和关闭时长不变。

任务横向列表采用连续滚动：拖动位移1:1跟手，松手使用原生 `OverScroller` 惯性，停在任意偏移而不吸附三张一页；首尾逻辑限位并支持弹性越界，新按下、多指、尺寸变化或卸载停止旧惯性并回收速度采样。卡片沿连续行排列，系统列表与本页快照缓存上限均为32项；选择当前最接近视口中心的三项，触摸和惯性结束后按需读取，不因每帧滑动发起系统快照。滚动期间任务列表变更延后应用，任务保护仍使用最新身份和可见性；无障碍滚动按单卡步进。

### 卡片视图复用与按压反馈

缩略图缓存与卡片视图分开管理。连续列表仅挂载当前相交视口的3～4张卡片，离屏视图卸载并放入至多4项复用池；不为32个任务各创建完整视图。复用时重置任务身份、标签、锁标记、按压、位移与动画；点击读取当前绑定身份，已打开菜单捕获当时身份。位图继续留在页面缓存中，回到可见区域直接取用。关闭页面同时释放缓存与复用池。

少于3张卡片仍接受横向拖动，增加边缘阻力后在松手时弹回原来的居中位置；取消、多指、尺寸变化与卸载停止旧动画。静止位置、尺寸和触摸区域保持不变。

预览的按压涟漪位于图像上层，使用与预览相同的物理圆角矩形遮罩，替代玻璃背景中的胶囊遮罩；图标降级和已加载快照均获得完整卡片反馈。

多任务快捷入口在窗口首次挂载前就进入任务模式，首次窗口参数不经过应用中心的背景模糊和DIM压暗。服务持有入场时序：将页面预置于屏幕下方，背景取样完成或降级后才执行一次500ms入场；AppHub不再同时启动另一段入场。由应用中心切入时同样先准备离屏状态，再更新窗口和取样。系统合成器的实际亮度过渡仍以三星真机体验为准。

### 清透边缘与统一边界回弹

任务预览参考 `LiquidToggle.kt` 按下态与用户补充的厚透镜图片，保留原有圆角和中心1.15倍凸透镜。折射带约16dp且不超过圆角的85%，最大采样位移为带宽的55%（常规尺寸约9dp），形成明显的边缘挤压与弯折；映射保持单调，不靠倒像制造光感。白色反射采用窄高斯峰，峰值距外沿约0.85dp，半高全宽约0.8–1dp，随朝向及肩部位置变化；不再叠加上下整片白色反射带。外沿带少量青蓝色散，接触阴影收窄至约1.9dp处；深入上下边缘3dp的纯色内容保持原色，玻璃厚度主要来自真实采样折射。快照和图标占位背景共用 `TaskPreviewView.EDGE_LIGHTING`，其他控制中心材质不变。

边界回弹统一适用于所有任务数量：超过三张时仍可从首尾向外拉动，逻辑滚动范围保持有效，额外距离以渐进阻力绘制；松手或取消回到同一边界，惯性到边缘允许有限越界后回弹。反向拖回内容区立即恢复1:1跟手，抓住回弹中的卡片可连续接手。页面缓存与四个卡片对象的复用上限保持不变。
