# 通知与控制中心玻璃材质

正式悬浮窗采用一次性背景会话，保留通知和控制中心的功能与网格格位，小屏工具采用统一紧凑规格。试验页的自由位移、示例背景菜单不进入正式版。

## 所有权与边界

- 通知、控制和浮窗启动器由 `InterfaceCard` 在显式打开时持有一次性 `PanelGlassSession`；任务页使用底部紧凑透明基础材质，不建立背景会话。`CoverService` 协调所选外屏、窗口与业务生命周期。只隐藏正在准备的新卡片，旧卡片保持可见；异步预算为150ms，到期显示轻量材质。关闭、息屏、断连、显示器坐标失效及低内存释放。配置关闭或省电模式不创建玻璃会话。容器与扩展参数见 `interface-cards.md`。
- Android 14及以上优先取所选显示器上最顶层、覆盖卡片安全正文范围的应用窗口，控制中心同时要求覆盖其状态栏，以避免把自己的悬浮表面采进背景。该范围直接使用当前方向的缺口、安全边界与正文布局结果，0°和180°分别计算；不要求应用窗口覆盖正文以外的系统区域，也不使用固定像素补偿。顶层应用未覆盖所需范围（例如裁切浮窗或分屏）时，普通打开使用该显示器一次取样；此回退可能包含现有悬浮工具。卡片互相推移时仅允许窗口取样，避免截入尚未退出的旧卡片。Android 13使用显示器取样；更早版本沿用基础材质。拒绝、受保护内容、超时与几何不一致不再重试，不回退到显示器0。
- `PanelGlassSession` 持有背景纹理、统一显示坐标、AGSL程序、显式接入的视图与至多一层弹窗父层纹理。同一卡片的编辑、详情和子表面复用背景，材质切换不重新取样；不同卡片的激活建立新会话，旧卡片滑出即释放。正在准备或已降级的同一卡片不重试；旧媒体控制与旋转方向入口仍接入。截图不保存、不轮询、不使用“保存外屏截图”的拆窗流程。
- `GlassBackdrop` 在串行工作线程预生成GPU模糊。原图最长边1024px，两份模糊最长边384px，半径分别按18dp、28dp及缩放换算。HardwareRenderer、Image、ImageReader和回调HardwareBuffer按所有权释放；迟到结果不得替换新会话。
- 窗口取样区分截图像素尺寸与屏幕显示尺寸：三星兼容缩放的普通 App 可返回等比例放大的 Surface，先映射到窗口实际显示范围，再生成纹理与模糊；不将原始像素尺寸当作屏幕坐标。不等比例裁剪、旋转尺寸错配及显示器取样尺寸不一致仍降级，受保护内容不重试。诊断同时列出取样尺寸和映射区域。
- `GlassSurface` 只对已绑定的面板树接入。布局变化时发现新增行、候选项和弹窗；绘制前仅检查已注册表面的可见坐标。没有玻璃自己的逐帧定时器。滚动、展开与拖拽采样位置随全局变换更新。
- 设置、原生 RemoteViews 启动器卡片和系统选择器不建立该会话；共享`Ui`不改。浮窗启动器全屏背板内的侧栏、应用区与独立 Dock 各有透明玻璃轮廓和折射，并借用同一张背景；临时 Dock 单独打开时只显示 Dock 表面。`LevelSlider`、编辑网格和详情背景只在有会话时使用可选材质。

## 视觉约定

通知页中央只显示原背景的76%亮度，不增加模糊，标题无玻璃底；页边有圆角与连续向外折射。通知卡片复用18dp模糊纹理，减轻白色覆层，正文采用更亮的次级文字和局部暗衬底。卡片侧滑离开列表时，边缘在至多12dp内渐隐；渐隐宽度随位移增加，静止卡片不变，操作按钮不参与渐隐。设置、关闭按钮为圆形，删除与数量同属胶囊。

通知滚动在边界回弹尚未结束时仍将正常阅读的松手交给原生 `ScrollView`，不因残余形变吞掉惯性；向外拉伸后反向拖入列表时，先耗尽本次拉伸，再交还剩余位移与原生速度采样。面板收起仍只累计到达列表边界后的继续外拉距离，原有70%弹性强度与取消规则保持不变。

控制页中央使用18dp模糊并压暗，按钮、滑条和媒体卡各自成形，保留当前开启／未知／执行中／禁用语义。编辑候选项与详情白图标使用深色选中底；详情文字按钮沿用浅色选中底与深色文字。

0.17.1 以主顶栏为基准，`PanelUi` 统一运行时标题17sp、正文12sp、辅助10sp、动作槽36dp、间距4dp、内容边距8dp；候选 Tab 和搜索占位约40dp。编辑网格标签沿用控制页的字号偏好。`PanelActionSlot` 将36dp圆按钮绘为28.8dp，保留整槽触摸；编辑和详情直接使用紧凑测量尺寸，不再继承设置页48dp的大留白。文本动作保持相同高度，宽度随文字；动态隐藏的播放器按钮连同槽位隐藏，恢复后重新参加布局。通知顶栏与侧滑动作按控制中心顶栏统一为36dp槽、28.8dp可见圆面及16dp可见图标，相邻槽不另加间距；带计数的清除胶囊按内容定宽。设置与清除只显示居中图标，完整动作名称保留在无障碍描述中；顺序液态分裂、停点分离及继续左拉合并清理见 `docs/liquid-tension.md`。通知应用图标与展开箭头在卡片内容区垂直居中；展开箭头沿用透明点击反馈，不接入玻璃底或白色选中态，以箭头方向和无障碍描述表达展开状态。不改主网格圆形磁贴、列数或系统操作。

`ControlSourceTabs` 现在仅是原生 View 宿主和无背景时的普通按钮降级。`OriginalLiquidTabs` 通过 ComposeView 直接调用作者原版 `LiquidBottomTabs.kt`、`LiquidBottomTab.kt` 及动画辅助文件，Backdrop 2.0.1 提供折射、色散、阴影与图文叠层。原文件按固定 commit 原样参与编译，原生宿主只对接来源回调、取消和多指防护、窗口生命周期，以及现有玻璃会话背景。组件以整体密度适配现有40dp槽，保留作者内部64dp轨道、56dp镜片及按压比例；设置与共享Ui不变。来源与校验值见 `docs/liquid-tabs-upstream.md`。`GlassToggle` 仍为原生View适配，使用已确认系统状态，未知态进入原选择流程。

NFC 主行及开关在回读时原位更新；状态和付款文字预留两行，执行反馈复用状态区，避免提示插入与整页重建造成两次尺寸跳动。写入确认到状态回读间保持禁用；未知结果和重试耗尽结束等待，不将旧状态作为新结果。关闭与断连释放现有订阅，不增加轮询。

Wi-Fi、蓝牙、移动数据、勿扰、飞行模式、手电筒、系统控制中心及自动旋转详情共用开关交互。点击后保留详情，复用原操作回调、状态回读或 Camera 回调结束过渡；一次性截止处理未确认结果。断连与状态失效同步打开的详情，迟到回调检查本次请求身份；手电筒只由匹配目标的回调结束等待。未知态先展开明确的开启／关闭文本操作。主网格仍保留圆形磁贴；通知设置和媒体系统选择器仍由系统呈现。

满屏页壳读取 WindowInsets 的物理圆角，半径减一像素覆盖抗锯齿接缝，展开过程中连续过渡至浮起圆角；子内容采用相同轮廓裁剪。候选 GridView 在绑定、重新挂载和临时回收结束时重新接入材质。滑条保留执行状态，但不因一次写入完成而切换整条边框颜色。

折射位移使用有界、单调的外向平滑曲线。通知及控制大背景板的折射带宽不超过12dp及局部几何上限，最大外向位移为带宽的80%（至多9.6dp），在窄边缘内增强扭曲感，同时减轻拖动越过背景文字后仍将其拉回板内的重影。其他控件保留22dp带宽上限及85%位移比例。通知页采样超出截图边界时只柔化边界的延伸颜色，避免把单个亮像素拉成白边，不镜像纹理、不折叠采样。文字与图标自身不参加背景模糊。来源 Tab 使用原版的隐藏图文叠层和组合 Backdrop：切换时镜片同时采样背景及覆盖到的多项Tab图文，原版自行处理局部放大、边缘弯曲及色散。此前自写的Tab缩放和AGSL折射已移除。新增的背景LayerBackdrop仅借用当前会话的sharp纹理，不新建截图；坐标由宿主与Canvas偏移对齐。无背景、低内存或卸载时销毁Composition并释放其图层，回到普通按钮。会话bytes仅统计其持有的背景位图，Compose活动图层不计入该数字。

详情打开前只记录一次当前本地父层，GPU合成仍在工作线程；最多保留一层。关闭或退出编辑确认窗会使旧结果失效。低内存降级在本次打开期间保持轻量材质，不能立即重新启用旧全窗／详情模糊。

## 验证入口

### 多任务页

`AppHubView` 请求进入／退出任务页时，由 `CoverService` 创建独立的任务或启动器 `InterfaceCard`。任务页使用全屏窗口与共享液态玻璃背板，正文按安全范围避让，三张预览并排定宽，名称和状态放在预览外，清理 × 居中置于下方留白。窗口不重复启用 DIM 或系统背景模糊；空白点击关闭，不透传到底层应用。底部紧凑横条与右侧局部磨砂实现已移除。

每次打开准备一份初始背景，静止期间不刷新。提交关闭可见任务时提前退役旧背景；窗口消失、边界或标题变化，以及来源窗口或所选外屏的活动系统窗口发出页面切换事件时同样退役。后者涵盖三星 Home 在同一宿主窗口内切到原生卡片／时间页的情况。只读窗口元数据与事件，不读节点树、不循环采样。旧纹理淡出后释放；确认新窗口后合并300ms内的切换事件，待手势、关闭队列和补位稳定时，在Android 14+仅用 takeScreenshotOfWindow 为新窗口取样一次，工作线程预处理，并向原 PanelGlassSession 转移纹理所有权。候选最多一份，窗口身份／边界／标题及会话在接纳前复核；任务页允许仅覆盖其安全正文区域的应用窗口取样（例如顶部留给状态栏），保留窗口真实屏幕坐标，不将浮动小窗口放大成整屏；取消、退出、换屏和效果关闭释放候选。失败保持透明降级，不自动轮询重试，不回退截图当前叠层。失效纹理不参加退出合成。任务快照透镜独立保留，不能随背景 `ready` 变为 false 而关闭。

前台 App 关闭或 Home 切换可能改变导航边衬。`CoverService.reconcile` 在同一外屏、相同尺寸、方向、密度和缺口的任务会话内推迟这类重挂载，保留正在跟手的 Carousel、请求队列和快照身份，退出后重新协调。锁屏、息屏、切屏及真实几何变化仍优先结束旧会话。不能通过重建任务正文来更新背景，也不能在系统请求结束后复活已关闭页面。

单项或批量关闭开始后暂停新增任务预览请求及迟到预览的显示；已返回且身份有效的预览只进入待显示缓存，与已显示缓存合计最多32项。关闭队列、手势和补位回弹全部稳定后才显示并恢复按需读取，入场仍允许立即请求预览。取消页面、任务消失或低内存同时清理两种缓存，迟到回调不得复活旧页；不让取样等待阻塞下一张卡片的上滑。

轻点空白处向下收起，空白拖动及取消回弹由 `PanelSurface` 交给 `AppHubView` 同步移动整个 `InterfaceCard`，正文与背板不能分离。卡片及完整清理触摸槽不算空白；超过触摸阈值的位移、多指、取消、尺寸变化及长按不会触发轻点收起。

`TaskPreviewView` 本身是每个任务唯一的玻璃卡片，不再嵌套外框。它借用任务页持有的快照，等比居中裁切，圆角直接采用页面背景所用的系统物理圆角半径（同样减去1px防接缝），不按卡片尺寸等比缩小；没有圆角报告时采用24dp视觉回退，仅在卡片过小时限制为短边的一半。专用凸透镜将中心正立放大约1.15倍，连续过渡至边缘，配合弧面高光、内侧暗边与底部反光；不复用来源Tab的凹透镜参数。名称和锁标记位于预览上方，状态位于预览下方，均不参与折射。关闭效果、省电或锁屏时保留同轮廓的圆角裁切；缺少快照时在同一轮廓内显示居中图标，图标不放大或裁切；快照到达后仅进行120ms图像淡入，不改变几何。

玻璃取样期间宿主可能暂时不可见，显示回调必须立即调用任务页的 `previewsVisible()`，不能等待应用中心约3秒的任务刷新周期。已经发出的快照在这段短暂隐藏期间到达时，只要页面代次、挂载和任务身份仍有效，就接纳结果并清除请求中标记；退出后的迟到结果仍释放。该修复移除人为等待，不承诺系统快照接口本身的返回耗时。

已加载的256px预览按任务身份在当前任务页内缓存，滑出视口仍保留，左右返回直接复用，不重复向系统读取。缓存至多32项，与系统任务列表上限一致；关闭任务页、断连或低内存清空全部，任务消失或身份变化只清理对应项。先移除绘制引用再回收位图，同一页内迟到的有效快照也可入缓存，旧页面回调必须丢弃。除交互动画及有界淡入外没有渲染定时器。`recent-tasks-glass` 模拟器场景检查硬件渲染、中心裁切与凸透镜像素、全屏底板与单层卡片、居中小按钮、锁定与连续滚动、会话缓存复用、背景释放、低内存、返回应用中心及显示后立即请求／隐藏期间回调；原 `recent-tasks` 场景覆盖任务手势和失败回调。

`UiSmokeInstrumentation` 的 `panel-glass` 场景仅接受可丢弃模拟器。它使用正式渲染层，覆盖五种背景、通知像素压暗、平移坐标、控制高频纹理模糊、3/4/5列、30项容量、编辑拖拽与取消、模态纹理释放、通知突发更新和原始Buffer迟到释放。使用`-e rotation 0/1/2/3`检查方向。

真实外屏必须另行验证一次性取样、窗口合成、双白条和息屏重建。应用服务的`dumpsys`输出背景状态、准备时间、取样／预处理次数及当前已接纳纹理字节数；关闭后明确报告0B。该数字不包含系统合成器与驱动缓存，不能替代PSS／Graphics测量。

具体构建、性能口径、真机证据与未测项目见`dist/开发设计/VALIDATION-0.17.0-panel-glass.md`。

### 单项上滑关闭与清理按钮

单张卡片上滑走 `AppRecentTasks.dismiss`，允许关闭所选外屏上的固定及前台任务，并保留固定入口。任务页 X 通过 `AppRecentTasks.clearPage` 关闭所有未锁定外屏任务，包括固定和使用中窗口；Dock 清理仍跳过固定、锁定和使用中任务。显式任务关闭走独立白名单 `recent_dismiss`，系统接口每次移除前重新校验任务身份、用户与显示器，不扩大到包级强行停止或主屏任务；任务移除不保证结束所有服务进程。

上下拉动采用渐进阻尼，预览、邻卡、清理及背景使用 `TaskForce` 共六节点的受力图，形变仅作用于预览，文字保持原比例。有效关闭从当前位置退场并自然补位，其他卡片保持可操作；请求按任务身份逐项提交，系统确认且退场后才移除，失败从当前状态回弹。取消、多指、尺寸变化及卸载释放旧触摸与速度。静止无持续帧循环，详细契约见 [多任务受力](task-force.md)。

首次打开及普通刷新为空时保留任务页，正中显示“当前没有后台任务”。明确关闭最后一项成功后通过独立空列表回调退出；失败、断连、不完整列表、请求中状态及迟到回调不算清空。X 清理成功后也走同一退出效果；清理失败保留任务页。清理退出共200ms：前60ms退掉卡片及液态玻璃，X 先小幅弹起再缩小淡出；局部 `InterfaceCard` 背板与正文同步淡出，不绘制截图或生成高斯纹理。完成后释放卡片与任务快照，隐藏并禁用空宿主窗口，退出中重开会取消旧动画并恢复原材质。

下方居中的 × 使用控制中心36dp触摸槽、28.8dp可见圆面和同一图标规格，并绑定共享玻璃；没有可批量清理任务时只降低图标亮度，不把整个玻璃按钮淡至30%，也不改变其他控制中心按钮。

任务页统一从屏幕底部向上进入、向下跟手收起。`InterfaceCard` 持有正文与背板，入场加减速传给 `TaskForce`，卡片产生有界的果冻反作用，X 与背景参与同一受力图。缩略图读取可与入场受力并行，不等待动画结束，不增加后台取样或人为延迟。

任务横向列表采用连续滚动，松手惯性和弹性居中由 `Carousel` 与 `TaskForce` 单一帧回调驱动，每次停止必有一张卡片居中，首尾和少于三项也相同。大惯性吸附提高阻尼并降低卡片节点偏移上限。系统列表与本页快照缓存上限均为32项，优先中心再读取可见邻卡，临时失败至多重试一次。当前可见任务按需读取一次系统任务快照，`updateCache=true` 保留系统保护；后台先读低分辨率缓存，缺失再读正常缓存，不截取整屏替代。滚动期间任务列表变更延后应用，任务保护仍使用最新身份和可见性；无障碍滚动按单卡步进。

### 卡片视图复用与按压反馈

缩略图缓存与卡片视图分开管理。连续列表仅挂载当前相交视口的3～4张卡片，离屏视图卸载并放入至多4项复用池；不为32个任务各创建完整视图。复用时重置任务身份、标签、锁标记、按压、位移与动画；点击读取当前绑定身份，已打开菜单捕获当时身份。位图继续留在页面缓存中，回到可见区域直接取用。关闭页面同时释放缓存与复用池。

少于3张卡片仍接受横向拖动，增加边缘阻力后在松手时弹回原来的居中位置；取消、多指、尺寸变化与卸载停止旧动画。静止位置、尺寸和触摸区域保持不变。

预览的按压涟漪位于图像上层，使用与预览相同的物理圆角矩形遮罩，替代玻璃背景中的胶囊遮罩；图标降级和已加载快照均获得完整卡片反馈。

多任务快捷入口在窗口首次挂载前就进入任务模式，首次窗口参数不经过应用中心的背景模糊和DIM压暗。服务持有入场时序：将全屏任务卡片预置于屏幕底部外侧，背景准备结束后执行统一卡片入场；AppHub不再同时启动另一段入场。由应用中心切入时同样先准备离屏状态，再更新全屏窗口。系统合成器的实际亮度过渡仍以三星真机体验为准。

### 清透边缘与统一边界回弹

任务预览参考 `LiquidToggle.kt` 按下态与用户补充的厚透镜图片，保留原有圆角和中心1.15倍凸透镜。折射带约16dp且不超过圆角的85%，最大采样位移为带宽的55%（常规尺寸约9dp），形成明显的边缘挤压与弯折；映射保持单调，不靠倒像制造光感。白色反射采用窄高斯峰，峰值距外沿约0.85dp，半高全宽约0.8–1dp，随朝向及肩部位置变化；不再叠加上下整片白色反射带。外沿带少量青蓝色散，接触阴影收窄至约1.9dp处；深入上下边缘3dp的纯色内容保持原色，玻璃厚度主要来自真实采样折射。快照和图标占位背景共用 `TaskPreviewView.EDGE_LIGHTING`，其他控制中心材质不变。

边界回弹统一适用于所有任务数量：超过三张时仍可从首尾向外拉动，逻辑滚动范围保持有效，额外距离以渐进阻力绘制；预览横向最多拉长18%、纵向收窄10%，文字不变形。松手与惯性触边后，位移和形变同步使用 `TaskSpring` 双次回弹；取消立即复位。反向拖回内容区立即恢复1:1跟手，抓住回弹中的卡片可连续接手。页面缓存与四个卡片对象的复用上限保持不变。
