## 桌面小组件四方向安全区（0.15.11）

- 原生组合卡片按当前显示方向的缺口、状态栏、快捷按钮与手势入口计算四边安全区。缺口转到左、上、右时相应避让，不将留白固定在底部，也不镜像缺口。
- 整张4×4画布只扣除一次安全区，再分配各组件尺寸与位置；已有实例不会因旋转后空间暂时变窄而被替换成占位或丢失绑定。
- [安装包与验证记录](../dist/VALIDATION-0.15.11-widget-safearea.md)。已覆盖安装到三星Z Flip5并确认原QQ音乐组件身份保留；四方向真机视觉仍需在对应卡片页面验收。

## 底部上滑与白条显隐（0.15.3）

- 根据侧边手势与系统返回冲突的实测反馈，所有方向均使用横向双白条和向上滑动：正常 0° 位于摄像头上方，90°／180°／270° 位于当前画面右下方。左侧通知、右侧控制中心，面板始终由下方展开，向下收起。
- 白条平时透明，上滑触发后从 0 淡入到 1，面板打开期间持续显示；关闭时先淡到 50%，在半透明状态等待 3 秒，再淡到 0。在等待或淡出期间重开面板会取消旧计时并恢复到 100%。
- 白条可见时长按可切换快捷按钮，完全隐藏时长按无效；隐藏不影响上滑入口及无障碍显式动作。快捷按钮仍在原位置，收起时不截获触摸。
- 缺口、快捷按钮和系统强制 Home 区域继续避让，不通过系统导航策略屏蔽 Home 或返回。详见 [0.15.3 验证记录](../dist/VALIDATION-0.15.3.md)。以下 0.15.1 的旋转位置说明是上一阶段方案，当前交互以本节为准。

## 摄像头内侧双白条（0.15.1，历史方案）

- 按四张位置参考图移动原双白条：摄像头在下方时位于其上沿；摄像头在左／上／右时，分别位于其右／下／左的屏幕边缘。入口随真实缺口旋转，不固定在画面顶部或底部，不保留第二组旧白条。
- 横向左条通知、右条控制中心；竖向上条通知、下条控制中心。仍向屏幕内部拖动打开，长按任意白条切换快捷按钮，短划回弹，多指或旋转取消。
- 快捷按钮保持原位置，点击、翻页和长按配置继续可用；按钮区域不再拉出面板，收起后旧窗口不可触摸。白条触摸区与面板正文、状态栏分开，控制中心编辑时不抢编辑手势。
- 优先读取所选外屏的缺口及系统强制手势边衬；缺口未报告时使用已有位置校准估计并在诊断中标明。不能由本地组件测试断言三星系统手势路由已通过。
- 构建及检查见 [0.15.1 验证记录](../dist/VALIDATION-0.15.1.md)。此前关于底部原入口和双白条与快捷按钮共用窗口的章节为历史说明，以本节为准。

## 0.9.9 Dock 统一滑出修复

- 点击Dock中的应用、从展开启动器启动应用、恢复最近任务，以及再次点击快捷栏Dock、点空白或切换面板，统一走180ms向下滑出流程，动画结束后才移除窗口；启动失败仍保留界面。
- 固定窗口宿主承载动画内容，重开沿用当前动画进度；退出中切到其他面板后再打开Dock会先关闭该面板，返回键优先处理当前面板。锁屏、显示器失效及服务卸载仍立即释放窗口。

## 0.9.8 Dock 弹性滑入与滑出

- 呼出Dock时从下方向上滑入并轻微回弹，基础时长340ms；手动关闭时180ms向下滑出，动画结束后移除窗口。系统动画倍率继续生效，关闭系统动画时直接完成。
- 动画途中再次点快捷栏入口，从当前可见位置反向继续；退出开始取消已有触摸与长按，防止重开后的旧抬手误启动应用。关闭期间任务恢复失败不再切换页面，也不会遗留忙碌状态。

- 主控制面板根据安全区宽高选择列数和行高，滑条跟随可用高度；刷新移入标题栏，删除底部常驻说明行。更多按钮或大字体允许滚动，不能为填满屏幕缩小到不可读。
- 通知默认小图标＋单行标题＋单行正文，真正发生截断时显示展开。更新保留当前卡片、滚动和展开状态；正文优先 BigText，单段最多 4096 字符。不提供系统隐藏的内容，也不声称已恢复完整聊天历史。
- Wi-Fi 详情读取真实的连接、保存与扫描缓存，手动扫描限频；点按网络进入系统选网界面完成选择与认证。本版没有自绘密码输入或直接连接保存网络，不保存 SSID 历史和密码。
- 媒体详情展示系统报告的本机输出和可转移设备，请求后等待路由回调；其他播放器远程会话使用系统媒体输出入口。未读取到状态时明确提示，不填充演示设备。
- 旋转磁贴轻点开启/关闭本工具自动旋转，长按选择四角度。开启时以当前握持姿态校准，方向稳定后作用于所选外屏；手动方向及按应用规则停止自动模式。当前模式只保存在进程内，息屏/锁屏/断连后停止，需手动重新开启。
- 内部详情使用 Android RenderEffect 模糊下层，跨应用背景沿用系统窗口模糊；没有截图轮询。系统关闭模糊、省电或关闭外观选项时回退，减少动画设置有效。

## 0.7.0 应用中心与任务 Dock

- 默认打开完整应用中心，显示侧栏、网格与 Dock，保留手动收起入口；首次打开不自动弹键盘，显示器重建保留当前展开状态。
- 展开的应用中心沿用“背景模糊（含应用中心）”开关，使用系统跨窗口 blur-behind 和半透明深色卡片，图标、文字及上层快捷栏保持清晰。模糊不可用时回退为实色卡片和背景压暗；收起时清除模糊/压暗，关闭时移除窗口并释放模糊状态监听。实现依据 [Android 窗口模糊接口](https://source.android.com/docs/core/display/window-blurs)，不读取或轮询其他应用截图。
- 点击底部 Dock 左右空白处关闭应用中心，点击区跟随实际 Dock 宽度变化；Dock 内应用、添加入口、清理按钮和状态文字保留原操作。拖动或取消触摸空白区不会误触关闭。
- 应用目录在进程启动时由低优先级后台线程预热，目录、名称和排序结果供应用中心与设置页共享。每个应用名称每轮扫描只读取一次；关闭应用中心不丢弃缓存。安装、卸载、更新、启用状态及语言/密度/深浅色模式变化会让缓存失效；关闭界面时不主动重扫，下一次使用时刷新。缓存只存在内存，不保存安装清单或使用历史到磁盘。
- 图标按需异步加载，统一缩小至 96×96 缓存，上限 4 MiB；重复请求合并，完成时只更新对应图标，不重建网格和 Dock。排队数量最多 96，低内存释放位图缓存，闲置工作线程 15 秒后回收。搜索使用已缓存文字，最近任务无变化时不重排整个应用列表；同步失败重试间隔延长至 15 秒，关闭或折叠后停止。
- Shizuku 连接状态未变化时不再重复通知观察者，避免“状态通知→重试连接”的重复调用；设置页状态文字相同时不重设文字。现有状态栏按分钟更新时钟（显示网速时每 2 秒），订阅随视图移除释放；本轮未添加常驻高频刷新。
- 应用中心按可用 dp 宽度计算列数，720×748 的 340dpi 和 440dpi 模拟器检查条件下均显示五列；侧栏 44dp、名称 8sp，网格图标 30dp、名称 9sp。搜索行内提供名称升/降序和系统最近任务优先。
- 底部常用独立于侧栏，最多固定 3 个应用；长按网格或底栏应用可固定/取消，设置页可调整顺序。旧版单个固定应用自动沿用。最多 5 个最近应用按包名去重，并排除固定常用。
- Dock 随实际数量收缩并居中，空分组不占位；无应用时只有添加入口。应用图标最大 28dp，清理按钮宽 20dp、图形约 14dp，压缩按钮周围空白。它属于应用中心，不替换原本摄像头旁的系统快捷栏。
- 最近项来自 Shizuku 读取的所选外屏、当前用户的系统最近任务，不再使用本工具启动历史模拟。仅展开且挂载的应用中心每 3 秒刷新一次，关闭、折叠或脱离窗口后停止，任务元数据仅在内存保存。
- 清理只请求移除当前最近组对应的非可见任务；固定应用、启动器、SystemUI、本工具和其他显示器/用户的任务均不进入清理目标。执行前逐项复核任务 ID、组件、用户、显示器及可见状态；执行后重新读取系统列表，按实际结果更新。系统拒绝或接口不兼容时显示不可用，不伪造清理成功。
- 此功能使用 Android 16 的系统任务接口，仍需验证 Flip5 / One UI 的权限和兼容性。移除最近任务由系统处理关联进程，不等同于强制停止全部后台服务；本版不执行 force-stop 或任意 shell 命令。340dpi 和 440dpi 为模拟器条件，非真机实测密度。
- 配置导出版本 7、布局版本 4，包含三个底部常用项及排序；继续导入旧配置。最近任务不写入配置、备份或诊断记录。

## 当前实现

- 独立外屏快捷栏：默认透明背景与白色图标黑色细描边，无彩色底板；可选纯黑实底、透明浅色或透明深色图标；滑动分页、起步阻尼、边缘回弹、长按图标区编辑。总数可设 2–5 个，其中始终有 1 个固定键：4 个即 3 个翻页键 + 1 个固定键。固定键默认“快捷应用中心”，可替换；横向默认在最右侧，左手模式在最左侧，纵向在最下方，不参与翻页。
- 单手布局：左手/右手分别调整固定键、应用收藏栏和控制滑条的位置，默认布局保留原有安排；仅调整安全区域内的顺序，不镜像异形缺口，不交换通知和控制手势入口。
- 桌面避让：三星桌面与系统面板默认仅保留双横条，普通应用显示按钮；长按任意横条临时切换，同一应用的各页保持选择，切换应用后恢复规则。收起时不画背景，触摸窗口缩为最多约 16dp 的细条，不让透明的大窗口挡住桌面。应用规则可编辑；识别不到外屏窗口时保留上次状态，首次识别前只留横条。锁屏、息屏仍隐藏，不绕过解锁。
- 白条只处理长按和从所在屏幕边缘向内拖动，不处理点击；按钮可见时，整个快捷栏的点击（包括白条上方对应位置）交给对应按钮。收成白条时点击不执行操作，长按仍切换按钮显示。
- 白条可见部分离触摸窗口外缘5dp，两端按至少10dp或长度10%内缩，左右两条等长，分页圆点与白条同线；图标与白条之间至少留3dp。绘制使用独立安全范围，屏幕最外缘仍是拖动触摸区，收起前后白条的物理位置不跳变。极窄布局按可用空间缩放。
- 白条附近外缘 14dp 内允许起手拉面板，紧凑双白条使用整个触摸条。先横偏、再向内的起步轨迹保留方向确认机会；超过触摸容差且向内位移达到沿边位移的 0.75 倍时跟随拉出。左半打开通知，右半打开控制中心，四方向使用对应的向内方向。
- 白条区域需明确沿边滑动至少24dp（且不小于两倍系统触摸容差）、沿边位移达到向内位移两倍，才确认翻页；明显向外滑动也交给分页。不明确的斜滑继续观察，松手取消，不误点按钮。紧凑双白条完全不翻页。按钮内部起手仍不能转成面板拖动，按钮区其他滑动按上／左下一页、下／右上一页处理，固定键可滑动但位置不动。方向确认后独占整个手势，保留短划回弹、多指、取消和长按互斥。
- 键盘避让：仅在所选外屏检测输入法窗口，出现时临时收起按钮，关闭后恢复之前的显示状态；期间长按仍可展开。相机/视频可通过应用规则整体收起，不判断是否正在拍摄或播放。轻震可在“手势入口”独立关闭。
- 布局备份与恢复：保存按钮、面板、侧栏、状态栏与四方向位置，恢复备份或默认布局后可撤销一次。用比例重算当前屏幕位置，保留目标显示器、权限和应用避让规则，不改变系统分辨率。
- 常驻状态条：时间、Wi-Fi、电量/充电、闹钟、最多 4 个通知应用图标；可选网速和双卡信号/网络类型。提供极简、日常、全部三种预设，各项仍可单独设置。网速是整机收发流量速率，不是测速；没有电话权限或未知信号时不虚构数据。
- 快捷应用中心直接打开完整应用网格；“应用 Dock”仅呼出临时底栏，点九宫格原位展开或收起。展开时侧栏与网格独立滚动，Dock不随列表滚动。长按应用可固定到底部或加入侧栏；打开应用后自动关闭相关临时界面，系统小窗能力由 One UI 决定。
- 控制中心采用小图标网格、极小名称标签、明暗开关状态与竖向亮度/音量滑条；控制中心顶部右侧显示电池与百分比，即使常驻状态栏隐藏了电池或百分比。未知状态使用小问号，不假装已开启或已关闭。设置页采用纯黑底和分组列表；内置图标统一为 Google Material Symbols Rounded 本地矢量资源。
- 内置动作和应用入口可增删、排序；快捷栏与快捷设置面板分别配置；支持 JSON 导入、导出。
- 直接选择系统 0°/90°/180°/270°，启用本工具的外屏方向感应，或将外屏旋转交回系统。工具自动和系统自由旋转是独立模式，物理方向仍需真机确认。
- 应用方向规则：为应用保存四个系统角度、跟随系统或沿用当前方向。仅从本工具显式打开应用时执行一次，不在后台强制方向、不在退出应用时恢复。旋转请求失败会提示并沿用当前方向打开；异步请求结束后重新检查外屏、亮屏与锁屏状态，目标改变时取消启动。实际角度和其他旋转工具的影响需真机确认。
- Wi-Fi、蓝牙、移动数据、勿扰、飞行模式、手电筒；读取不到状态时显示未知，并提供明确的开启/关闭操作。移动数据在本版采用明确的开启/关闭选择，不把通用设置值误当成当前 SIM 的状态。
- 外屏亮度使用带 displayId 的接口，失败时禁用，不改用主屏亮度。媒体音量及播放按键作用于手机的媒体会话。
- 返回、主页、最近任务、锁屏；使用指定显示器截图，保存到 `Pictures/FlipCover`，尊重系统安全窗口限制。
- “通知”按钮请求系统原生通知面板，在三星上由 One UI 提供。此公共无障碍动作不能指定 displayId，是否在外屏展开需真机验证，不承诺可移植主屏的原生 SystemUI。原有列表保留为可添加的“应用内通知”，支持清除可清除通知、打开原通知入口；它需要通知使用权。系统可能隐藏敏感通知内容；本版不提供内联回复。
- 可选背景模糊：使用 Android 12+ 的跨窗口 blur-behind，不截屏、不缓存其他应用画面；系统不支持或暂时禁用时恢复黑底。快捷栏在模糊层之上，保留用户选择的透明或纯黑外观。实际外屏模糊能力受 One UI 和图形配置影响。
- 发现其他应用提供的 Android 标准 `TileService`，固定到面板或快捷栏，提供“注册系统”与点击请求。属于实验性兼容能力，不能承诺所有应用、动态图标、实时状态、长按菜单或外屏弹窗兼容。
- 读取外屏尺寸、缺口和密度；自动定位失败时支持手动校准。锁屏、息屏隐藏；保留暂停入口。

这里的“已实现”表示源代码已包含相应路径；本机功能是否可用，以实际授权和设备检测为准。电脑编译成功不等于 One UI 真机验收。

0.6.0 根据真机截图压缩通知、控制面板、设置与应用中心，加入透明描边、状态大小和独立百分比开关。模拟器能验证原生组件，实际异形屏尺寸、圆角、三星前台窗口报告与手指命中范围仍需在 Flip5 上确认。选择 5 键会缩窄单键的触摸宽度，不能保证每个键的两个方向都有 44dp。阶段结果见 `ITERATION_PLAN.md`，逐页像素评估见 `dist/UI_AUDIT-0.6.0.md`。

## 0.6.0 真机反馈调整

- 通知面板收到通知变化时只更新对应卡片，保留窗口、列表容器和既有行位置；内容未变时不重设文字或滚动位置。新增通知放入列表，移除通知只删该卡片。针对频繁更新的常驻通知，避免过去整窗重建引起的闪烁。
- 状态栏默认改为原尺寸的 70%；“状态栏 → 显示大小”可在 50%–150% 调整，拖动实时预览，松手保存，避免反复重建服务窗口。常驻百分比默认关闭，电池图标仍显示；控制中心右侧始终显示百分比。
- “悬浮栏外观”提供透明描边、纯黑、透明浅色、透明深色。描边提高明暗背景可读性，不是读取前台应用颜色的系统级自动黑白切换，不截屏取色。透明模式不再用局部黑块遮住应用内容；纯黑状态带补齐安全区域外缘间隙。悬浮层不会替其他应用预留布局空间。
- 用户已在三星设置关闭外屏导航条，本版默认关闭“导航条未关闭时向内避让”。触摸窗口延伸至屏幕最外缘，紧凑双横条也保留贴边命中。物理屏幕外没有触摸事件，以手指进入触摸窗口外缘后的起点和向内轨迹判定。启用导航避让后入口随窗口向内偏移；不修改系统导航策略。旧配置中的轻点白条开关仍可导入，但不再启用点击打开面板，导出固定为关闭。
- 面板使用全显示区域背景，内容止于实际缺口和快捷栏可见边界；移除旧的大触摸区预留带、额外空白页脚和面板边缘露底。控制中心自己的状态行替代常驻状态行，不重复占用两行。
- 通知的应用名、标题和清除键共用首行；正文最多三行。压缩卡片内边距、卡片间距、设置标题和列表行高，长文字仍可换行，避免用大块空白撑开短内容。空通知、未播放媒体和未检测到外屏的空状态保留真实信息，不为填满屏幕新增内容。
- Android 不允许排除强制 Home 手势。本版没有写入全局沉浸式设置、关闭三星导航或拦截系统导航；局部手势排除只辅助非强制手势，不能承诺跨过 One UI 的系统层优先级。
- 应用中心侧栏宽度从 64dp 减为 52dp，图标 27dp 减为 22dp；编辑/设置合并到菜单，旁边为展开键。底部未选固定应用时仅保留小型添加入口。应用网格按可用 dp 宽度自动选列（53dp 目标列宽），图标 34dp 减为 25dp，搜索行和间距收紧。系统字体缩放仍受尊重；长名称省略但完整名称保留在可访问性描述。

## 首次安装与设置

1. 安装 `dist/FlipCover-0.10.0-debug.apk`。这是本项目的个人验证候选包，新增三星原生外屏小组件入口，兼容边界与验证说明见 `dist/VALIDATION-0.10.0.md`。独立包名为 `io.github.flipcover.controls.debug`，不会覆盖原来的两个工具；已装本项目旧版本时可覆盖更新。从 0.1/0.2 升级时默认固定键“快捷设置”会改为“快捷应用中心”，其他自定义固定键保留。
2. 从外屏启动器打开“外屏快捷栏”，启动 Shizuku 后在“权限中心”连接/授权。
3. 在应用内进入无障碍设置，启用“外屏快捷栏”。如果系统要求先允许受限设置，在本应用的系统信息页手动处理；本应用不会自动写入无障碍授权名单。
4. 通知使用权、相机与电话状态权限按需授权；相机仅用于手电筒，电话状态仅用于信号/网络类型，不读取号码。未授予可选权限时，其他功能仍可使用。
5. 先运行“只读兼容性检测”，确认外屏 ID 和分辨率。自动识别不确定时手动选择，主屏 0 不允许作为目标。
6. 开启“开启外屏助手”。如位置不合适，进入“屏幕适配”，关闭自动定位，按当前旋转方向调整角落、长度和厚度。
7. 使用本应用控制旋转前，关闭原工具里的自动旋转。原工具的“刘海避让”等入口可能再次更改方向。
8. 添加应用磁贴：编辑 → 应用磁贴 → 注册系统 → 添加。注册会向系统快捷设置提交添加请求，可能改变原系统面板中的磁贴列表。
9. 在“底部快捷栏”设置总数、固定按钮及翻页顺序，预览可滑动；在“何时显示快捷栏”配置桌面避让规则。更换固定键时原固定键尽量移回翻页区，最多 30 个翻页项。在“控制中心”设置模糊开关。
10. 配置导出使用版本 13 / 布局版本 9，覆盖快捷栏、控制中心、状态栏、四方向位置、显隐/避让/应用方向规则、四个常驻应用、桌面与文件夹、别名和显示偏好，并包含原生小组件的提供方、格位与尺寸模板；兼容配置版本 1–12。小组件模板导入后，在组合卡片编辑页选择「从配置模板恢复」，逐项重新授权，点击完成才替换原卡片。显示器选择、权限、服务总开关、本机系统控制限制、历史备份和临时状态不迁移。文件上限为256 KiB，无效数据整体拒绝。详见[配置导出覆盖评估](../docs/configuration-export-coverage.md)。
11. 调好布局后，在“布局备份与恢复”保存；需要恢复时使用备份或默认布局，误操作可点“撤销上次恢复”。保存新备份会替换旧备份，恢复不会删除备份。
12. 在“单手布局”选择握持侧；在“应用方向”搜索应用并保存方向，下次从快捷栏或应用中心打开时生效；在“常驻状态栏”选择预设，再按需微调项目。布局恢复不会删除应用方向规则，完整迁移使用配置导出。

自动避让需要无障碍的窗口检索能力：应用只读取外屏窗口编号、类型和事件中的应用包名，不请求页面节点树或文字。升级后若旧的服务授权没有加载新能力，可在系统设置手动关闭再开启本工具的无障碍服务。前台窗口记录只在内存保留最多 32 条映射，不写入诊断报告或导出配置。

Shizuku 通过无线调试启动时，重启手机后一般需要重新启动。通知授权和 Shizuku 授权互不替代。

## 快捷栏常驻与恢复

快捷栏属于无障碍服务的外屏窗口，不属于设置 Activity。服务启用、显示开关开启、目标外屏亮起且系统未报告锁屏时，切换应用仍保留。0.3.0 默认在三星桌面与系统面板收成双横条，属于主动避让，不是服务退出；长按任意横条可展开。打开和关闭本工具控制面板不关闭入口。

0.1.1 修正了无障碍 `onInterrupt` 被当成窗口关闭信号的问题。窗口切换、亮屏、解锁、显示器变化后检查并恢复快捷栏；检查发现窗口已脱离时重新挂载，几何未变且仍挂载时保留原窗口和分页。检查由事件触发，额外做一次延迟复查，不使用后台无限轮询。窗口使用外屏的 `TYPE_ACCESSIBILITY_OVERLAY` WindowContext。

锁屏、息屏、暂停或关闭无障碍时仍会隐藏。本版没有新增后台保活权限，不能承诺系统强制停止或撤销无障碍后仍显示。若切换后仍消失，打开“只读兼容性检测”复制结果；其中包含版本、服务状态、窗口是否挂载、显示器状态、系统锁屏标志，以及当前进程最近 10 条状态变化（仅内存保存），不包含前台应用名称或通知正文。One UI 外屏是否存在独立的锁屏状态仍需真机判断，不能据此自动解除锁屏限制。

## 权限与实现参考

对提供的 APK 做了只读静态分析，借鉴的是调用边界，未复制或重打包它们的代码和资源：

| 参考工具 | 观察到的机制 | 本项目选择 |
| --- | --- | --- |

## 异形区域的边界

720×748 是整体像素矩形。额外区域没有在代码中写死成“351×66”；该数值只是早期参考资料的条件估计。应用读取当前 `DisplayCutout` 的边界矩形，再计算可放置区域。边界矩形不一定完全描述弯曲边缘，因此保留内缩与人工校准。

当系统没有报告缺口时，46% 长度 / 8.8% 厚度只是可编辑的初始比例，界面会标记需校准。这里读取的是当前显示坐标，可能受原工具设置的分辨率覆盖影响；必须结合物理屏幕观察确认。

## 构建

使用 JDK 17、Android SDK Platform 36、Build Tools 35.0.0、Platform Tools。Gradle Wrapper 固定 8.13，Android Gradle Plugin 固定 8.13.2；安装对应 SDK 后设置 `ANDROID_HOME` 或由 Android Studio 管理 SDK 路径。

macOS / Linux，在项目根目录运行：

```sh
./gradlew :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
```

Windows 在相同目录运行 `gradlew.bat :app:assembleDebug :app:testDebugUnitTest :app:lintDebug`。产物位于 `Cache/build-output.nosync/app/outputs/apk/debug/app-debug.apk`，测试和 Lint 报告位于同目录的 `reports/`。生成目录使用 `.nosync` 后缀避开 iCloud 同步副本，在其他平台是普通目录；源码与 `dist/` 交付目录不受影响。调试签名用于个人验证；发布版签名尚未配置。

`Cache/` 只保存当前电脑的构建缓存、工具和检查记录，不是运行依赖。SDK 和 JDK 的绝对路径不写入项目配置。原始 APK 是参考输入，不进入应用构建。
