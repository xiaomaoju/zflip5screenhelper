# 配置导出覆盖评估

评估对象：当前应用源码，配置版本 14、布局版本 10。入口为「备份与关于 → 导出配置 / 导入配置」。完整迁移使用配置文件；「布局备份与恢复」是本机布局快照，不包含所有行为偏好。

## 可迁移功能

下表各项均由 JSON 导出与导入路径覆盖。版本 14 新增 Home 按钮效果，布局版本 10 同步包含此项；继续接受配置版本 1–13。旧文件缺少 Home 配置时默认返回原生卡片，缺少小组件模板时保留已导入的模板。

| 功能 | 导出内容 | JSON 字段 |
| --- | --- | --- |
| 快捷栏 | 动作/应用/磁贴入口及排序、固定按钮、每页数量、起步阻尼 | `dock`、`pinned`、`perPage`、`damping`（布局中也有） |
| Home 按钮效果 | 返回三星时钟首页或原生应用中心所在卡片页 | `layout.homeAction`：`clock` / `cards`；默认 `cards`，布局备份、恢复与撤销共用 |
| 控制中心 | 快捷项和排序、3/4/5列、密度、名称及字号、工具区位置、亮度/音量/媒体工具开关、空闲媒体显示、模糊 | `panel`、`blur`、`layout.panelColumns`、`layout.panelOptions` |
| 侧栏常用项 | 常用动作、应用入口及顺序 | `favorites` |
| 外观与状态栏 | 外观样式、启用、七个状态项目、缩放、电池百分比、左右安全留白 | `layout.chrome`、`statusEnabled`、`statusItems`、`layout.statusScale`、`layout.batteryPercent`、`layout.statusSafeLeft/Right` |
| 手势与显隐 | 白条手势开关、轻震、自动收起、应用避让列表、键盘避让 | `gestures`、`haptics`、`dockAutoHide`、`compactApps`、`avoidKeyboard` |
| 导航避让与屏幕适配 | 导航避让及偏移、自动定位、四方向角落、长度/厚度比例、左右手布局 | `layout.avoidNavigation`、`navigationGap`、`automatic`、`corners`、`width/height`、`hand` |
| 应用 Dock | 最多四个常驻应用及顺序，与桌面和文件夹互斥 | `layout.hubPins`，兼容字段 `hubPinned` |
| 应用中心 | 排序方式、应用格位、网格基准尺寸、自动补位、布局锁、名称/角标显示、密度、应用别名 | `layout.hubSort`、`workspace`、`workspaceColumns/Rows`、`workspaceCompact/Locked/Labels/Badges/Density/Aliases` |
| 文件夹 | 身份、名称、成员及顺序、颜色、2×2格位 | `layout.workspace[]` 中的 `id/name/members/color/slot` |
| 应用方向规则 | 每个应用的显式启动方向 | `rotations` |
| 原生组合小组件 | 来源卡片编号、组件提供方、4×4内的位置及尺寸；不包含实例身份 | `widgetTemplates[].slot/items`，每项为 `provider/x/y/width/height` |

手势字段中的旧 `tapHandles` 仅兼容历史配置，当前导出固定为关闭，不恢复轻点白条打开面板。

## 明确保留在本机或不属于配置的内容

| 功能/数据 | 处理方式与原因 |
| --- | --- |
| 目标显示器、服务总开关 | 导入保留本机选择及启停状态，不能将另一设备的显示编号或启用状态直接应用 |
| 无障碍、通知访问、Shizuku 等授权 | 由用户和系统管理，不能通过 JSON 自动授权 |
| 系统控制中心禁用选择 | `system_controls_disabled` 按项目约定仅本机保存，不进入配置或布局备份 |
| 原生组合小组件的绑定和内容 | 模板可迁移；`native_widgets` 中的宿主/组件实例身份、授权和第三方组件内部配置不能迁移，恢复时重新授权及配置 |
| 本机布局备份、时间及撤销历史 | 完整配置文件保存当前配置，不包含本机历史；导入保留布局备份和恢复撤销，清除控制中心旧撤销 |
| 通知正文、最近任务/锁定、系统快照、媒体会话、临时显隐、未提交编辑草稿 | 临时运行状态，不进入配置文件 |
| 亮度、音量、网络等实时系统状态 | 只迁移入口与工具显示偏好，不自动重放系统操作；显示器分辨率/DPI/当前旋转也不迁移 |
| 升级迁移标记、目录/图标/搜索缓存 | 本机内部状态，无需导出 |

因此，现有可迁移用户设置及小组件布局模板均已覆盖；系统权限、设备绑定和临时运行状态需在目标设备重新建立。

## 小组件模板恢复

1. 在原设备导出配置。文件包含当前已保存的组合卡片布局及之前导入、尚保留的模板；相同模板不重复追加。未完成的卡片草稿不导出。
2. 在目标设备导入文件。这一步只保存模板，不申请授权、不替换任何现有卡片。
3. 从三星外屏添加组合卡片或打开现有卡片编辑页，选择「从配置模板恢复」。任意模板可用于当前卡片，原卡片编号仅帮助识别。
4. 确认替换当前编辑草稿，再逐项点击「授权并恢复这个组件」。沿用系统授权及第三方配置页面。系统已允许的授权仍需由用户点击恢复触发，不通过导入自动执行。
5. 未安装、已卸载或不支持原尺寸的组件显示不可用；可重试，或明确跳过并保留空位。返回可停止剩余恢复、检查部分草稿或放弃修改。
6. 检查草稿后点击「完成」提交。提交前原卡片及其绑定保持不变；放弃只释放本会话新建实例。旋转重建保留步骤，目标外屏改变后停止旧回调。

模板只描述布局，不保存第三方组件的账号、内容、内部配置或锁屏权限。当前卡片含不可用组件时，导出明确提示先移除/更换该组件，避免生成无法解释的残缺模板。文件仍限制 256 KiB；保留的导入模板可在组合卡片管理页明确清除，不删除当前卡片。模板列表每页最多显示20份，避免大量配置一次渲染所有行。

## 本次补强

- 配置/布局版本、每页数量、阻尼及四方向角落要求整数，拒绝字符串和小数截断。
- 开关要求 JSON 布尔值，拒绝用字符串代替；可选列表显式给出错误类型或 `null` 时拒绝，旧文件缺省字段仍按兼容规则处理。
- 导入时校验 Dock 常驻应用与桌面、文件夹成员的唯一归属。
- 修正避让应用名单超过500项时能导出却无法导入的问题，保留整体文件大小限制。
- 小组件模板校验提供方、整数格位、边界、最多16项及无重叠；规范化时只保存提供方和几何数据。
- 所有校验完成后才提交一个偏好编辑器，失败不部分写入。
- `configuration` 模拟器测试逐键比较完整配置导出/导入后的持久化值，同时检查本机状态保留、边界尺寸、错误类型、跨区域重复、后置校验失败及配置版本 1–14 的顶层兼容路径；Home 检查覆盖两种模式、布局备份恢复撤销、非法值原子拒绝和旧布局默认值。历史布局结构继续由已有专项测试覆盖。
- 原生组件检查新增模板实际导出、缺失提供方、拒绝授权、跳过/放弃、重建续接、逐项新建身份和最后提交路径。

## 验证入口与边界

项目根目录构建：`./gradlew :app:assembleDebug :app:assembleDebugAndroidTest :app:testDebugUnitTest :app:lintDebug`。

安装两份调试 APK 到可丢弃模拟器后执行：`adb -s <模拟器序列号> shell am instrument -w -e scenario configuration io.github.flipcover.controls.debug.test/io.github.flipcover.controls.UiSmokeInstrumentation`。该检查仅允许模拟器运行，结束后恢复测试前偏好。

构建与检查记录：`Cache/tests/configuration-export/`。此测试直接调用应用的 JSON 导出/导入方法，不证明系统文件选择器、云端文档提供方或三星物理外屏上的完整文件迁移流程；这些仍需真机验收。

2026-09-28 本轮结果：调试 APK 与 instrumentation APK 构建成功，95项单元测试零失败；`configuration` 通过130项断言；`native-widgets`、`native-widgets-narrow`（640×748）及 `native-widgets-wide`（800×748）各通过134项断言。检查了实际恢复页和提供方缺失页的渲染，原始图仅存于 Cache，不作为带设备框的最终效果图。

整项目 Lint 已执行；当次报告的8项错误均位于共享目录中另一项开发工作的 `LauncherWidgetViews.java`（API版本兼容），本次配置/模板文件没有 Lint 错误。该结果不等于整项目 Lint 通过，也未在连接的三星真机上安装或验证。
