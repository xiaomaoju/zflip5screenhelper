# 基础界面六键导航

适用版本：0.18.4（versionCode 62）。日常操作使用上、下、左、右、确认和取消。实体键盘对应方向键、Enter/数字键盘Enter/中心键、Esc/返回；方向模式鼠标对应移动、左键、右键。

## 通用操作

- 助手获得键盘输入后，进入页面即选中主要内容；蓝框为选中，暖色框为调整。触摸时隐藏键盘装饰。
- 确认主项目执行一次；需要次级动作时选中“⋯”再确认。按住确认不会连开应用或连续开关。
- 取消依次退出文字/数值调整、更多位置、菜单/弹窗、组件内部、文件夹或页面。取消不会关闭设备规则。
- 按住取消500毫秒或按F6进入当前窗口中的快捷栏。左右移动、跨组自动翻页，确认执行，取消/F6返回原控件；长按释放不会再触发短按返回。界面底部导航边界也可向下进入。
- 快捷栏复用现有按钮与固定项，不更改显隐偏好。输入框和弹窗内进入快捷栏不提交文字；返回保留光标。未保存布局草稿仍遵循退出确认；原生组件编辑先完成或取消，不能用快捷栏跳过草稿处理。
- 滑条/分段控件确认后调整，方向改变值，确认或取消退出调整。数值按原有提交方式生效，取消不是撤销。
- 会话内保留目标身份及来源，删除后选择相邻项；设置原有导航栈保留滚动和搜索，配置重建恢复有界焦点记忆。身份不写入布局备份。

## 各页操作

| 页面 | 六键路径 |
| --- | --- |
| 浮窗启动器 | 固定5×3格位移动，确认启动应用/打开文件夹；上到搜索/排序，下到分页再到Dock；靠侧栏边界进入侧栏，反向恢复应用选择。分页区域左右切页，应用格边缘不自动翻页。 |
| 文件夹 | 按实际成员行列选择并确认；边界停留。取消回到桌面上的该文件夹。 |
| 控制中心 | 按网格移动；右选择本按钮“⋯”，再右到下一个按钮，左反向经过附加动作。确认主体执行原开关，确认更多打开原详情。工具区可达亮度、音量和媒体；顶部刷新保留，编辑不纳入基础焦点。 |
| 通知 | 上下选择通知或分组；确认打开通知/展开分组；右选更多，确认后可展开正文、通知设置、清除。不可清除的通知不提供可执行清除。菜单期间内容变更会阻止过期操作。 |
| 任务 | 左右选择并居中，确认恢复；上选更多，菜单使用既有锁定、关闭、刷新；下到清理。空列表确认可打开刷新菜单，取消可返回。清理仍遵守任务身份、显示器和锁定规则。 |
| 设置 | 上下选择设置行，同排独立选项左右切换；确认切换/进入。输入框确认进入文字输入，方向移动光标，取消退出输入并保留文字；再取消按真实来源返回。 |
| 详情/外接设备 | 焦点限制在最上层弹窗，标题动作、正文、底部按钮可达。取消先退出调整再关闭，回到来源；异步更新按稳定身份保留选择。 |
| 原生启动器 | 按应用、侧栏、分页和Dock区域导航；取消先退文件夹，再结束辅助输入。原生卡片的编辑入口仍遵守已有触摸说明。 |
| 原生组合卡片 | 先选择组件，确认进入其按钮；根容器整卡点击也保留为动作。取消先回组件层，再把输入交还三星。 |

## 实现与权限

`InputSurface` 处理六键、快捷栏、模态范围和按键生命周期；`InputNavigation` 定义目标与区域。主要页面绑定原业务动作，简单弹窗才使用几何邻近选择。`CoverService` 协调现有快捷栏动作；原生桥接器的可见会话序号防止顶层取消后刷新重新抢焦点。

不新增权限、root、驱动或系统输入注入。仅助手自己的输入窗口及精确可见的助手卡片生效。外部应用、三星其他页面、系统授权和文件选择器遵循系统本身输入规则。

**范围不包括控制中心编辑、启动器编辑、拖拽排序及复杂组件布局编辑。** 原有触摸入口保留。第三方RemoteViews的特殊控件、集合滚动和固件差异需要逐组件实测；自有按钮导航通过不能证明所有第三方组件兼容。
