# 鼠标、触控板与键盘导航

入口为 **设置 → 鼠标与触控板**。控制中心的 **外接设备** 打开同窗口液态玻璃弹窗，提供设备规则、设备选择、模式、灵敏度、识别设备和临时恢复指针；右上角进入完整设置。旧配置首次迁移在控制中心不足30项时追加按钮，满额时可在编辑器手动添加。

## 使用

1. 在系统蓝牙设置配对鼠标/触控板，或连接 USB 设备。
2. 打开“设备操作规则”，选中对应设备，选择“方向导航”。未知设备默认使用系统指针；可以为另一台设备保留“指针操作”。
3. 移动跨过阈值后选择上下左右邻项，左键确认，右键逐层返回；选中“⋯”后确认打开更多操作。长按确认不会重复执行。滑条与分段选择器先确认进入调整，再移动改变数值。
4. 实体键盘无需启用鼠标规则：方向键选择、Enter确认、Esc/返回逐层退出。按住取消500毫秒或按F6打开快捷栏，左右选择并跨组翻页，取消/F6恢复原位置。输入框内方向键保留文字光标移动。取消不暂停设备规则；如需恢复指针，使用“外接设备”中的显式按钮。
5. 各页六键操作、范围与验收见 [基础界面六键导航](six-key-navigation.md)。

Android对鼠标、触控板、触摸导航设备的分类由设备上报信息决定，不能仅凭设备名称判断硬件。页面展示系统分类，识别设备时消费下一次设备操作；同名不同标识分别保存，标识重复时保持指针模式。配置最多保存32台设备，断连后保留配置，可手动删除。

## 实现边界

- `InputDevices` 由 `CoverApp` 共享，使用 `InputManager.InputDeviceListener` 发现设备，不轮询。`InputSteps` 负责阈值、主轴与残留距离；捕获后设备源可能变成 `SOURCE_MOUSE_RELATIVE`，仍按原设备身份路由。
- `InputSurface` 统一按下/释放、长按取消、模态范围和同窗口快捷栏；`InputNavigation` 提供稳定目标、区域邻接与有界会话记忆。基础浏览覆盖设置、通知、控制中心、详情、任务、文件夹和启动器；控制中心、启动器及复杂布局编辑不列入六键验收，保留触摸入口。
- Pointer Capture 属于整个窗口，Android没有逐鼠标捕获开关。A使用方向导航而B保留指针时，B在捕获窗口内使用本地绘制指针及本地触摸派发，事件不进入系统输入注入接口；窗口外恢复系统路由。独立指针模式的系统速度仍由系统管理。
- 普通应用内导航不需要root、驱动修改或Shizuku。运行时悬浮窗使用原有无障碍服务；原有系统操作仍遵守原有授权，不因输入功能获得额外权限。
- 便携配置导出包含总开关 `inputEnabled`；设备标识、每设备绑定及临时暂停留在本机，布局导入不覆盖这些身份。
- `InputPopupMenu` 在方向导航时将已有菜单放入当前窗口，避免另开菜单窗口打断捕获。

## 三星原生卡片

三星继续显示卡片。`LauncherWidgetBridge` 与 `NativeWidgetBridge` 根据三星可见性回调记录精确实例，仅在唯一实例、所选副屏亮屏且解锁、顶层应用窗口为三星卡片宿主、助手自己的面板已关闭时启用辅助输入窗口。多实例可见、切换到其他卡片/应用、锁屏、息屏或窗口释放时关闭辅助输入；进程重启不把缓存的可见标记当成新回调。

`NativeCardInput` 使用带真实实例身份、零额外内边距的 `AppWidgetHostView` 加载已发布的 RemoteViews，正文透明，仅绘制导航反馈；集合适配器与原有 PendingIntent 保留。它不读取三星或其他应用的无障碍页面树，也不截图重放点击。捕获失败有提示并释放窗口；回到助手或离开该卡片后可重试。

这覆盖助手的原生启动器与组合卡片，不是三星所有原生页面的全局方向导航。第三方小组件集合、特殊点击区及其他三星固件仍应逐项验证。
