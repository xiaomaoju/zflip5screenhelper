# 控制中心一级界面：单网格弹簧与预设拉伸

体验入口：[离线 HTML 原型](../dist/html/control-force-jelly.html)。本版按照“网格先拉到极限，再拉整个界面”的要求替换了此前10节点网络。已按审核方案接入原生 Android 控制中心；原型的一级横滑仍是交互提案，原生沿用 `InterfaceCard` 既有入口、切换和收起路由。原生验证见 [开发验收](../dist/开发设计/VALIDATION-0.17.3-control-motion.md)。

## 交互与唯一受力状态

整个网格共用一个一维弹簧：拉力距离 `load`、速度 `velocity`、固定锚点0。不存在四排节点、逐按钮节点或滑条/媒体/背板节点，也没有区域之间的成对连接。普通滚动仅保存偏移与衰减速度；开启、卡片切换和收起是有期限的解析曲线，不做整页物理积分。

| 阶段 | 网格 | 整个界面 |
| --- | --- | --- |
| 正常滚动 | 先滚动既有列表，固定四行视口 | 无弹性形变 |
| 到边界继续拉，`abs(load) ≤ 150` | 非线性橡皮筋，越拉越紧，位移逐渐到48原型像素 | 维持原形 |
| 拉力超过150 | 网格局部位移硬限制为48，不再继续向外移 | 剩余拉力直接映射为竖向伸长，最多5.5%；横向轻微收窄 |
| 松手 | 捕获松手时的位移，随唯一弹簧的统一恢复进度立即回缩 | 捕获松手时的伸长量，按相同进度同步回缩，不先清掉整页形变再动网格 |

阈值和画布尺寸属于原型示意，Android使用真实dp与现有滚动边界，不把原型像素直接写成dp。

局部位移：`sign(load) × 48 × (1-exp(-min(abs(load),150)/45)) / (1-exp(-150/45))`。

整页拉伸（拉动阶段）：`clamp((abs(load)-150)/250,0,1) × 0.055`。

**回弹阶段使用独立的映射规则，仍只有原来一个弹簧。** 松手时一次记录 `load₀`、已显示的网格位移 `grid₀` 和整页伸长 `whole₀`。每帧从同一弹簧计算 `q=clamp(load/load₀,-0.15,1)`，网格位移=`grid₀×q`，整页伸长=`whole₀×q`。这样两者在衰减开始的同一帧同步恢复，不再把拉动阶段的“网格固定48、整页先消退”的限制套到回弹。轻微反向余振也共用此进度，返回时保留原拉动方向的变形锚点。

再次触摸网格时，即使方向尚未判定，也立即冻结当前回弹并清除旧速度；按住不动停帧，避免首个移动使用旧基准突然跳回。随后仍沿当前映射接续，重新拉回原松手幅度或越过零点后才恢复普通拉动规则；稳定、关闭、切换和减弱动效时清除这三个快照值。快照只在开始回弹时创建一次，不增加积分节点、连接或逐帧临时数组。

回弹只有 `v += (-180×load - damping×v)×dt`、`load += v×dt`。使用不大于8ms子步，单帧最多消费32ms。拉力状态上限400、松手速度限幅600，位置与速度到阈值后归零并停止帧。下边界反向使用同一公式；回弹中的轻微反向位移与整页微压缩共享同一进度。

## 点击、开启和切换

- **按钮弹性加重**：按下在80ms内压到约89%×86%；抬起用320ms预设关键帧依次弹到113%×110%、回到97.5%×98%、最后100%。只变换当前按钮的图形，标签和邻居不参与；业务动作立即执行原有入口。键盘点击走相同弹性；滑动、取消、多指与失焦取消旧按压，不误触开关。
- **滑条点击与方向感**：亮度和音量均用180ms非线性缩小、480ms非线性放大恢复；点击只有起点和终点两帧，不超过原尺寸、不多次弹跳。拖动时按最近触摸速度直接映射 `clamp(velocity×0.004,-6,6)` 原型像素的竖向偏移，向上划就微微上移，向下划就下移；55ms短过渡柔化方向反转。松手用280ms有限关键帧微微反向回摆再归零，不另建滑条弹簧。数值与填充直接跟手，填充仍用 `scaleY`；取消恢复原值。
- **开启**：背板与正文同步入场，用560ms有限时长位移与解析拉伸曲线模拟惯性。各功能区不设质量、速度或独立弹簧。
- **左右切换**：手势位移直接跟手，最多约4%整页横向拉伸；松手用220–360ms短位移曲线接续。横滑未越阈值则回原位，不把控制网格改成横向分页。
- **收起**：从当前卡片位移继续，正文与背板共用同一变换。卡片过渡与网格弹簧互不扩大为区域力图。
- **音乐卡片**：卡片空白、封面和文字区域均接受整块局部按压，按下用180ms非线性缩至96%×97.5%，松手用480ms非线性恢复到100%；没有超出原尺寸或多次弹跳。播放/切歌按钮同时保留原图标弹性。音乐卡片只展示反馈，不打开二级页面；Enter或空格也可体验。
- **局部错相余弹**：拉动时所有模块继承同一整页拉伸；放下后，顶栏、右上编辑按钮、右上刷新按钮、亮度、音量、音乐分别播放固定的轻微位移与伸缩曲线，网格继续使用唯一弹簧。具体延迟/幅度如下；无随机数、无独立模块积分。重新触摸取消旧局部余弹，优先恢复共享跟手状态，不累积旧余振；被取消的局部修正最多4原型像素。惯性滚动撞到边界也使用同一局部反馈。
- **减弱动效**：关闭拉伸、过冲、方向微移与局部余弹，保留数值跟手和短促点击反馈。

### 固定局部余弹参数

| 模块 | 延迟 | 时长 | 最大位移 | 最大局部纵向修正 |
| --- | --- | --- | --- | --- |
| 顶栏 | 0ms | 330ms | 1.5原型px | 0.6% |
| 编辑按钮 | 12ms | 380ms | 2.2原型px | 1.2% |
| 刷新按钮 | 42ms | 420ms | 2.8原型px | 1.4% |
| 亮度 | 0ms | 370ms | 4原型px | 1.8% |
| 音量 | 30ms | 410ms | 3.2原型px | 1.4% |
| 音乐 | 55ms | 470ms | 3.8原型px | 1.2% |

强度由放下时的拉力与速度确定，限制在上表幅度内。相同输入得到相同曲线，模块轻重差异来自固定参数。局部位移先轻微反向，回摆约32%，随后归零；没有循环或永久抖动。延迟与时长由浏览器有限动画调度，不使用六套定时器或帧回调。

## 顶栏入口

去掉控制中心的×和加号，保留编辑、刷新。关闭仍使用既有手势；原型侧栏的“跟手收起”仅是演示按钮，不是设备内新增入口。

编辑与添加不是完全相同的初始状态：当前 `CoverService` 的编辑直接进入编辑器，原加号进入同一编辑器后立即展开候选区。因此设计统一为一个编辑入口，在编辑器内进行添加、移除和排序，不丢失添加能力。本原型不进入二级编辑器；原生已删除加号和控制中心关闭×，保留原位编辑与刷新，添加能力保留在编辑器候选区。

## 绘制与命中

原型将现有可见图形移动到一个 `card-paint` 层，网格图形再共用一个 `gridPaint` 层。没有复制图标或文字树；原按钮与滑条保留在固定的语义/命中层，网格正常滚动偏移仍同步命中层，弹性视觉变换不改变原控件的触摸范围。

整页到限拉伸时，文字会随整页产生上限5.5%的短暂视觉拉伸，这是本版整页形变要求的明确选择。静止字号、布局及无障碍范围不变；按钮局部弹性不缩放标签。滑条与音乐使用独立的方向位移、局部余弹、按压三层可见容器，和父级共享拉伸相乘，各动画不会争抢同一个transform。文字随模块按压/余弹有有限瞬态形变，静止字号不变。顶部状态行随整页视觉变换，白条入口与标准外框不参与形变。

## 性能分析

以下为源码可证明的工作量变化，不能解释为真机FPS或耗电提升比例。

| 成本 | 原10节点原型 | 本版 |
| --- | --- | --- |
| 区域物理状态 | 10个二维区域弹簧 | 1个一维网格弹簧 |
| 区域成对连接 | 16条，每子步遍历 | 0条；网格仅连接固定锚点 |
| 按压解算 | 10区域按压＋24按钮按压每子步积分 | 当前按钮或滑条/音乐表面才启动有限关键帧；媒体按钮点击最多两层反馈，不在自有帧循环积分 |
| 逐帧临时数据 | `nodes.map`分配受力对象，反复查节点索引 | 网格标量直接更新，无受力数组/对象分配 |
| 模块局部余弹 | 区域和邻排各自解算 | 放下时至多6个有限动画；不在自有帧循环写模块变换 |
| 按钮图形逐帧写入 | 遍历24项，各写4个CSS变量 | 常规帧不遍历按钮；网格与整页共用容器变换 |
| 普通帧样式写入 | 约116次，不含邻卡 | 6次，不含邻卡；没有按钮逐项写入 |
| 诊断画布 | 默认已创建2D上下文并每帧清空 | 默认0×0、不创建上下文；只有打开“显示唯一弹簧”才分配绘制，关闭释放画布尺寸 |
| 按住不动 | `gesture`存在即持续申请帧 | 没有移动或回弹就停帧；按压保持由有限局部动画完成 |
| 常驻合成提示 | `scene/neighbor`持续`will-change` | 卡片过渡、网格交互时临时开启，结束后复原 |
| 页面隐藏 | 停止物理帧 | 停止物理帧并取消所有局部按钮动画 |
| 窗口失焦 | 取消旧手势后回稳 | 取消当前手势与按压，允许网格/卡片有限回稳后停帧 |

本次点击增加了滑条/音乐表面的局部动画，拖动时增加一个事件驱动位移；网格放下后最多6个局部关键帧并行，最后一个在525ms内结束。它们会增加浏览器动画合成成本，但不会增加网格积分数量或常规自有帧的逐模块写入。局部动画结束后还原，隐藏、关闭、切换及减弱动效会取消；重新触摸优先取消旧局部余弹。

减少节点不是全部性能收益；更关键的是移除逐按钮帧写入、子步临时分配和多个动态表面。浏览器关键帧由动画系统调度，仍会产生合成/绘制成本，不能宣称“零计算”。整个网格与整页都是同一已绘制内容的变换，不改测量、不重建窗口。

**剩余主要成本是玻璃、模糊、裁切和大面积合成。** 本原型仅背板保留一次 `backdrop-filter`，没有为按钮或滑条新增背景模糊。但整页变换是否促使浏览器重绘/重采样取决于实际合成实现，模拟DOM不能证明GPU成本。Android应复用既有 `PanelGlassSession` 纹理，对缓存表面做 `Canvas`/合成变换，避免重新截图、逐区域模糊与动画中重新测量；极限整页拉伸仅在超过网格阈值时使用。

原生实现采用 `ControlElastic` 单标量积分，`ControlScrollView` 拥有边界手势、回弹帧及六个模块的有限余弹注册。`ControlFeedback` 与 `RuntimeVisuals` 绘制按压；`InterfaceCard` 仍拥有卡片位移和释放，`LevelSlider` 仍拥有事务提交和取消，`MediaCardView` 仍按挂载订阅。没有完整 `ControlForce` 多节点力图；所有权契约已同步到 `AGENTS.md`。

## 原生实现与性能边界

`Panels.ControlDashboard` 保留原来的列数、四行可视网格、格位、侧栏及紧凑布局。只有 `ControlScrollView` 的边界回弹启动自有帧回调；持指不动即停帧，正常列表滚动由 `ScrollView` 处理。网格22dp处达到局部上限，后续拉力映射为最多5.5%整页纵向拉伸。回弹捕获网格/整页形变快照，由同一恢复进度同时衰减；再次按下立即冻结，方向识别期间不会继续回弹。反向拉回零后直接交接给原生滚动，不向子磁贴发送新的按下，避免短距离反转误点。

原生按钮局部动画只作用图形，不缩放标签；亮度、音量、音乐的整块按压沿180ms缩小、480ms恢复的单调曲线，没有过冲。滑条方向位移上限2.7dp，松手280ms有限回摆。顶栏、编辑、刷新、亮度、音量、音乐使用固定延迟与时长，位移上限依次为0.7/1/1.3/1.8/1.45/1.7dp；这六项由有限 `ValueAnimator` 调度，没有六套物理积分。取消、多指、真实尺寸变化、卸载、卡片退出都释放旧手势、速度跟踪器和回弹；系统动画关闭时不保留按压、拉伸或方向偏移。

`GlassSurface` 使用复用的矩阵，将实际绘制的按压、局部位移、网格和整页变换传给既有材质采样。网格画布使用内容坐标锚点，材质矩阵使用视口锚点，避免非零滚动位置重复加入偏移。没有新增截图、背景取样、纹理、订阅或轮询，也不在动效中测量布局。动画会使现有玻璃表面重绘，Canvas 变换仍有 GPU 合成成本；模拟器功能与像素检查不能量化三星真机帧率、耗电或驱动成本。

## 胶囊读数加载

音量在控件创建时同步读取系统媒体音量并显示当前值。控制中心打开或刷新且桥接空闲时，优先发出所选外屏的亮度读取，完成后再读取通用开关状态；繁忙时仍使用既有有界请求队列。显示器、页面身份和请求序列校验继续保护迟到结果，刷新不会替代正在等待提交的用户亮度。

`LevelSlider` 将真实目标值与绘制值分开。读取结果在首次可见绘制前返回时直接使用真实值；可见期间返回时，填充高度、图标分色边界和百分比沿300ms插值同步更新。尚不可用时保持“—”，不把占位值当作系统读数。重复相同目标不会重启动画，新的目标从当前绘制高度继续；手动拖动、键盘及无障碍设置直接接管，显示动画不提交系统写入，隐藏与卸载释放时钟。设备端检查入口为 `control-level-loading` 和 `brightness-flow`。
