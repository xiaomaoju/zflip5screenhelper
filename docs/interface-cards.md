# 运行时界面卡片

`InterfaceCard` 提供界面背板（任务页为底部紧凑透明基础材质，其余页面为全屏液态玻璃）、整个卡片的进出位移、旧卡片触摸隔离和一次性背景资源释放。`CoverService` 管理窗口、所选外屏与当前／正在退出的业务宿主。内容的网格、通知行、任务预览和启动动作仍归原内容组件。

启动器使用两个预先挂载的宿主窗口，均在状态栏、快捷栏和双白条之前创建，分别容纳当前与正在退出的卡片。打开 Dock 及切换页面只更新宿主内容与窗口属性，不移除再添加顶层控件。关闭时释放卡片、玻璃和订阅，清空宿主并使其不可见、不可触摸且不可聚焦；息屏、显示器切换或窗口重建时移除两个宿主。两个空宿主不保留业务视图或返回历史。

系统导航栏返回 Home 时，`CoverService` 接收系统 `CLOSE_SYSTEM_DIALOGS` 的 `homekey` 原因，立即取消入场、拖动及切换中的旧卡片并开始退出。通知、控制、编辑、详情、完整启动器和任务页统一向上滑出；仅单独打开的 Dock 向下收起。退出从实际位置开始，正文和背板一起移动，期间窗口不可触摸／聚焦，旧背景立即释放，编辑草稿不提交。关闭完成释放内容、订阅和缓存，保留隐藏宿主及常驻控件；重复 Home 和迟到的启动结果不能重开旧页。系统广播未提供显示器身份时只关闭已挂载的所选外屏临时界面，不向其他屏幕发送导航操作。`recentapps`、`gestureNav` 等其他原因不当作 Home；锁屏、息屏及显示器移除仍立即释放窗口。本地入口 `UiSmokeInstrumentation -e scenario cover-home` 覆盖九类界面、两个入口方向、退出方向、打断切换、重复请求、草稿与窗口释放；系统广播和导航手势另外在物理真机验证。

| --- | --- | --- | --- | --- |
| CONTROLS | FROSTED | true | true | false |
| NOTIFICATIONS | TRANSPARENT | false | true | false |
| TASKS | TRANSPARENT | false | true | false |
| LAUNCHER | TRANSPARENT | false | true | false |

类型声明集中在 `InterfaceCard.java`。修改 `Definition` 的材质参数即可改变背板；`showStatusBar` 决定创建顶部状态栏、正文避让和随容器卸载释放订阅。状态栏复用控制中心原有强制电量百分比及安全区几何，不依赖常驻状态栏开关；控制中心编辑只隐藏该行，完成恢复同一行。任务内容自行处理安全区，容器向它提供扣除状态栏后的区域，避免重复留白。

`useSafeArea` 控制正文的安全区避让，默认开启；`useCardSafeArea` 决定背板采用安全区小框或完整视口大框，现有四页全部保持 false，背板填满各自视口。两者独立。背板切成小框时取物理缺口与快捷栏边界计算的安全范围，不因状态栏开关重复缩小；正文再独立避让状态栏和白条触摸区。小背板仍限制其内部正文；大背板加安全正文时，正文格位保持。关闭正文安全区才允许它使用容器可用范围，不改变系统手势。

白条的正文避让不能混同于卡片边界：滚动视口停在白条上方，背板继续覆盖白条区域。背景跨正文安全边界时，在20dp范围内逐渐混入预先生成的强模糊；安全正文底部在16dp范围内渐隐，顶部状态栏保持清晰。大背板的不安全边缘同样使用该玻璃过渡。正文末项仍通过滚动完整查看，渐变不改变列表容量；背景不可取样时降级为透明压暗和正文渐隐，不虚构真实背景模糊。

运行时正文由 `CoverService.contentInsets` 读取当前所选显示器的可见系统栏、强制手势和物理缺口四边边衬，`resolveContentGeometry` 将其与快捷栏、白条及自有状态栏边界取交集，重叠避让不重复相加。隐藏导航栏的旧尺寸只保留给用户主动开启的快捷按钮导航避让，不进入正文安全范围。通知、控制中心、编辑与详情使用面板范围；任务页与两个启动器宿主共用启动器范围；组合卡片按白条绘制边界计算后使用同一系统安全范围。启动器按原规则整体上移以避开底部系统区，只由系统安全区及物理缺口、快捷栏限制上移范围，允许与本应用常驻状态栏重叠。系统区抬高状态栏时同步下移顶部白条绘制位置，入口触摸原点仍遵守独立边缘规则。全屏窗口和玻璃背板不随正文内缩；任务会话期间仅系统边衬变化仍按既有规则延后到退出处理，真实旋转、尺寸变化立即重建。

回归入口为 `DockGeometryTest` 和模拟器 `UiSmokeInstrumentation -e scenario runtime-safe-area`，覆盖四个方向、系统区四边、导航栏显隐、缺口缺失及状态栏开关，并检查真实控件测量和全屏背板。原始组件图片仅用于本地验证，不作为最终效果图或三星宿主兼容性证明。

180° 单独压紧顶部双白条绘制下方的空触摸尾部：保留原触摸起点、横向两半和白条绘制位置，触摸区结束在白条下方3dp。其余三个方向沿用原入口尺寸。先按原入口计算正文视口高度，再将释放的空间用于垂直居中，避免因此放大网格或通知列表。通知与控制中心的标题、正文视口及页内操作一起布局，独立状态行固定；任务页的预览、名称与清理按钮共用居中后的任务范围。内容更新和滚动不重算居中位置，只有显示几何变化才重算。缺口、可见系统栏及强制手势仍优先；空间不足沿用尺寸约束与滚动。全屏背板不内缩，点击坐标随实际布局更新。

启动器保持四层表面：全屏卡片背板，侧栏透明玻璃，应用区透明玻璃，以及独立的透明玻璃 Dock。三块内部表面各有自己的边缘折射、圆角和留白，几何沿用 `AppLauncherStyle`。它们共享本卡片的一次背景取样；Dock 单独打开时隐藏全屏背板和应用区，保留 Dock 自己的材质。原生三星启动器卡片仍采用 RemoteViews 适配，不取样宿主背景。

内部三块玻璃的正文区域复用本次取样已生成的强模糊纹理，并限制亮背景的亮度，避免底层应用文字和按钮被误认为启动器内容；边缘保留折射，全屏背板的透明参数不变。背景效果关闭、取样失败或低内存释放时，内部区域使用有对比度的基础表面，不增加取样或模糊缓存。

搜索与排序整体绑定一块与应用区相同圆角的输入玻璃，不额外给文字控件重复铺底。Dock 清理扫把及九宫格入口保留点击反馈，但不绑定独立玻璃按钮，Dock 容器的玻璃背景保持。侧栏设置为独立圆形玻璃按钮，直径与侧栏宽度相同；布局与宿主差异见 `docs/launcher-hosts.md`。

手动下拉启动器时，`AppHubView` 把位移交给父级 `InterfaceCard`，保持自身位移为零，使背板与正文从第一次有效 MOVE 起一起跟手。Dock 的第一阶段反向补偿仍保留。反向拖动和取消沿同一位移路径回弹；松手提交时，`CoverService` 从背板当前实际位置继续向下退出，即使启动器原先从顶部进入，也不能重置位置或改回入场方向。独立 Dock 及非卡片宿主仍保留原有收起判定。

四种卡片可以相互替换。任务页统一从底部向上进入、向下收起，和 Dock 相同，不随快捷栏所在边变化；顶部入口向下划入，底部入口向上划入，快捷图标沿当前面板入口方向从屏幕外进入；启动器底部手势替换其他卡片时固定向上。初始90ms单独插值：新卡片从屏幕外连续跨过入口前的 unsafe area，同时旧卡片从当前大框连续裁至安全小框；入口位置偏移不能直接加到旧卡片的位移上。初始插值完成后，新旧卡片按手指实际移动距离跟随。视口坐标和正文测量保持固定，只改变绘制轮廓、裁切和位移，不在动画中重排内容。每次显示仍保持各自固定的视口，退出时的临时裁切不修改该参数。

替换时，旧卡片的位移同时受两张卡片实际绘制边界约束，包含当前裁切和入口偏移；相邻边缘至少保留6dp间隙。新卡片刚进入视口时连续展开间隙，取消时连续收回，避免在初始插值或回弹端点瞬移。该规则由容器统一执行，任务与其他页面可使用不同的窗口原点与视口尺寸；动画期间不改变各自静止尺寸。

旧卡片移出可见范围即释放窗口、玻璃与业务订阅。只保留当前过渡所需的旧对象，不能形成返回历史；尚未滑出的取消手势反向插值并恢复原对象的轮廓和位置，已滑出的卡片不能因反向滑动或关闭新页面重新出现。玻璃准备期间保存当前手势进度，显示后通过初始插值追上手指，不直接瞬移到积累的进度。

新增页面应声明 `Definition(id, material, showStatusBar, useSafeArea, useCardSafeArea)`，三参数构造默认安全正文和大背板。把内容 View 和暂停／释放回调交给容器，再将显式入口接入 `CoverService`。不另写背板、截图循环、公共入场几何或第二套顶部状态栏。修改运行中的材质使用 `material(...)`，它重绑现有背景，不重建正文或重复取样。

本地验证入口为 `UiSmokeInstrumentation -e scenario interface-card`，覆盖四页的全部24种顶部／底部定向替换、取消回弹、滑出释放、状态栏及材质参数。`panel-entry` 覆盖双白条原生触摸入口。模拟器使用真实 application-panel 窗口和合成背景，只证明应用侧逻辑；三星外屏无障碍窗口路由、系统导航拦截和真实背景取样仍需物理真机验证。

`LauncherSidebarView` 在启动器就位后播放共享液态张力分裂：初始整体表面包住设置，沿纵轴收缩并保留连接颈部，最终成为侧栏与下方圆形。它复用本会话强模糊纹理和同一Renderer，不取样新背景；独立设置点击语义与静止尺寸不变。文件夹采用专属 `FOLDER` 表面与共享圆角资源，成员刷新保留绑定，并更新恢复背景及玻璃染色。
