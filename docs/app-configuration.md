# 常用开发配置

根目录 `app-config.json` 集中常用调节项，修改后重新构建 APK 生效；不要求所有配置或每个数字都放入该文件。

## 后续配置规则

- 新增常用调节项优先进入此文件，分为 `update`、`defaults`、`appearance`、`motion`；所属代码、共享样式或构建任务读取对应值，不另存同义参数值。
- 包名、版本、SDK、依赖和签名入口仍在 Gradle；固定网格、容量与安全约束、内部缓存上限、请求编号、兼容迁移标记、设置页的稳定样式及局部算法系数留在所属模块。
- 迁移已有参数时保留当前值、合法范围、持久化键和模块职责；两种启动器等共享功能继续由共享层读取，不分别定义配置。
- JSON 顶层 `schemaVersion` 当前为 `1`。模块按需添加真实字段，不预先创建没有消费者的配置。
- 单位写入字段名，例如 `Ms`、`Bytes`、`Hours`；枚举、合法范围和消费者在本文件中记录。配置缺失或非法必须明确报错，不静默采用代码里的备用服务器或参数值。
- `Prefs` 继续保存用户在软件内修改的偏好。以后迁移的默认值仅在偏好尚未保存时生效，不通过更新总配置覆盖用户已有设置。
- 签名密钥、密码、访问令牌不放进随 APK 分发的总配置，继续使用独立安全配置。

## 已接入的模块

| 分组 | 内容 |
| --- | --- |
| `update` | 更新服务器、连接/读取超时、下载限制与更新缓存期限 |
| `defaults` | 默认快捷项与顺序、主要开关、状态栏规格、控制中心和启动器默认选项 |
| `appearance` | 启动器图标/字号/侧栏/Dock/文件夹规格、公共面板字号与圆角、状态栏文字/阴影、玻璃模糊强度 |
| `motion` | 卡片时长、任务回弹、控制中心弹簧、启动器弹簧调节与分裂、二级面板弹簧、顶栏/Dock分裂、白条淡出等待 |

`defaults` 只在对应偏好不存在时生效，改变默认值不会覆盖已保存的用户设置。默认快捷项及固定入口使用 `ActionCatalog` 已注册的内置动作标识，应用和磁贴由用户设置管理。控制中心“重置”使用配置中的默认组合，原有撤销保留；状态栏/控制中心的命名预设、旧文件导入的兼容默认值和首次升级的历史迁移保持原语义。用户应用名单、布局、权限、设备身份和系统实时信息保持原来的管理方式。

`Dp` 为逻辑尺寸，`Sp` 为跟随字体缩放的字号，`Ms` 为毫秒，比例为无单位数。启动器仍使用固定字号和真实显示密度，固定5×3；文件夹仍为2×2占位、最多9项；控制中心列数只允许3/4/5、可视4行。两种启动器共用 `AppLauncherStyle` 和生成的圆角资源。

`gradle/app-config.gradle` 校验字段、类型、范围及基本尺寸关系，生成 `BuildConfig` 常量。`app/build.gradle` 生成资源，`Prefs`、`AppLauncherStyle`、`PanelUi` 及各动效所有者继续负责消费和计算。只迁移主要调节项，局部几何公式、节点网络、命中规则等仍留在代码中；运行时动效不读取 JSON。

消费者：`AppConfig` 将 `update` 解析为不可变配置，`AppUpdater` 使用它进行检查和下载。Gradle 的 `prepareAppConfig` 校验根文件，生成原样资产副本和网络安全资源；HTTP 只按配置中的主机放行，HTTPS 默认禁止明文流量。

## 修改与生效

在项目根目录修改 `app-config.json`，然后通过正常 Gradle 构建生成新 APK。源文件由 `prepareAppConfig` 原样复制到 `Cache/build-output.nosync/app/generated/app-config/assets/app-config.json` 并随 APK 打包；不编辑生成副本，也不在 `app/src/main/assets/` 保留第二份手工配置。

配置值生成的常量和启动器圆角资源也位于 `Cache/build-output.nosync/app/`，不手工维护。拼错字段、缺少字段、错误类型、越界值或不合适的图标/容器尺寸会使构建明确失败。新增调节项时同时添加根配置中的值、Gradle 校验和所属共享模块的消费入口。

当前是随构建生效的开发配置，不提供手机内编辑、远程改写或总配置导入。现有用户配置导入导出不包含更新服务器地址或开发参数。构建和验证命令见 README；Windows 使用 `gradlew.bat`。

## 设置界面大小

`appearance.settings.baseScale` 为主设置页面及自有设置弹窗的基础缩放，默认 `0.7`（整体缩小30%）。`defaults.settings.scale` 为用户缩放默认值 `100`，软件内可调70%–130%，实际缩放为基础值乘以用户百分比。组合卡片配置及其全部子页保持既有100%尺寸；系统选择器、运行时浮窗和显示密度不参与。用户的设置缩放仅本机保存，不随运行时布局或配置备份迁移。
